# ANI:WHERE — 애니 팝업 카페 지도

전국에서 열리는 애니메이션 캐릭터 팝업·콜라보 카페를 **지도 한 장**에 모으는 웹 앱입니다.
누구나 등록·수정할 수 있고, 팔로우한 팝업은 **내 캘린더**에, 오늘 열린 팝업은 **데일리 팝업 노트**에 모아 보여 줍니다.

| | 주소 |
| --- | --- |
| 🌐 바로 써 보기 (배포된 사이트) | https://ani-where.streamlit.app |
| 💻 소스 코드 (GitHub) | https://github.com/ayla-seoan/ANI-WHERE |

> 설치 없이 구경만 하려면 위 **배포된 사이트**를 열면 됩니다. 내 컴퓨터에서 직접 실행해 보려면 아래 순서를 그대로 따라 하세요.

## 1. 내 컴퓨터에서 실행하기 (처음부터 따라 하기)

> ⏱ 처음이라도 10분이면 됩니다. **API 키가 하나도 없어도 앱 전체가 돌아갑니다.**

### 1-1. 준비물 설치 (한 번만)

| 준비물 | 받는 곳 | 확인 방법 (터미널에 입력) |
| --- | --- | --- |
| **Python 3.10 이상** | https://www.python.org/downloads/ | `python --version` (Mac 은 `python3 --version`) |
| **Git** | https://git-scm.com/downloads | `git --version` |

- **Windows:** Python 설치 첫 화면에서 **`Add python.exe to PATH`** 를 꼭 체크하세요.
- **터미널 여는 법:** Windows 는 시작 메뉴에서 `PowerShell`, Mac 은 `Spotlight(⌘+Space)` → `터미널`.

### 1-2. 코드 내려받기

터미널에 한 줄씩 입력합니다.

```bash
git clone https://github.com/ayla-seoan/ANI-WHERE.git
cd ANI-WHERE
```

> Git 이 어렵다면 GitHub 페이지의 초록색 **Code → Download ZIP** 으로 받아 압축을 풀고, 그 폴더에서 터미널을 열어도 됩니다.

### 1-3. 가상환경 만들고 패키지 설치

가상환경은 이 프로젝트 전용 파이썬 공간입니다. 다른 프로그램과 섞이지 않게 해 줍니다.

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Mac / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- 성공하면 터미널 맨 앞에 `(.venv)` 가 붙습니다.
- Windows 에서 `activate` 가 "스크립트를 실행할 수 없습니다" 로 막히면, 먼저 아래를 한 번 입력하고 다시 해 보세요.
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

### 1-4. 실행

```bash
streamlit run app_cafemap.py
```

- 브라우저가 자동으로 **http://localhost:8501** 을 엽니다. 안 열리면 주소창에 직접 입력하세요.
- 처음 열면 `data/` 폴더의 예시 팝업들이 리스트로 보입니다.
- 끌 때는 터미널에서 **`Ctrl + C`**.

### 1-5. 다음에 다시 실행할 때

```bash
cd ANI-WHERE
.venv\Scripts\activate          # Mac: source .venv/bin/activate
streamlit run app_cafemap.py
```

### 1-6. 최신 코드로 업데이트

```bash
git pull
pip install -r requirements.txt   # 패키지가 바뀌었을 수 있어 한 번 더
```

## 2. 화면 사용법

### 처음 화면 — 리스트 전체보기

- 맨 위 **검색 · 작품 · 캐릭터 · 진행여부 · 날짜** 로 거릅니다. **초기화** 로 처음 상태로 돌아갑니다.
- 목록 위 **팔로우 스위치**를 켜면(→ `팔로잉`) 내가 팔로우한 팝업만 보입니다. 옆에서 **지역**과 **정렬**도 고를 수 있습니다.
- 카드 오른쪽 아래 **팔로우 스위치**로 팝업을 팔로우합니다. 팔로우한 팝업은 내 캘린더에 들어갑니다.
- 카드를 누르면 **상세 화면**이 열립니다.

### 지도보기 (화면 아래 가운데 `지도보기` 버튼)

| 왼쪽 — 데일리 팝업 노트 | 가운데 — 지도 | 오른쪽 — 내 캘린더 |
| --- | --- | --- |
| 오늘(‹ › 로 날짜 이동) 열려 있는 팝업. 지역도 ‹ › 로 넘깁니다. **내 위치에서 가까운 지역부터** 보여 줍니다 (제목 옆 `?` 에 안내). 목록을 누르면 지도에서 그 위치를 보여 줍니다 | 처음엔 **내 주변**이 보입니다. 점을 한 번 누르면 미리보기, **한 번 더 누르면 상세**. 오른쪽 위에서 `밝은 회색 / 컬러 / 다크` 지도 모양을 고릅니다 | 팔로우한 팝업이 날짜에 막대로 표시됩니다 (연속된 날은 한 막대). 막대에 마우스를 올리면 미리보기, 아래에 **곧 있는 팝업** 목록 |

> 📍 처음 지도보기를 열면 브라우저가 **위치 권한**을 묻습니다. 허용하면 내 주변이 먼저 나옵니다. 위치는 지역 순서를 정하는 데만 쓰고 저장하지 않습니다.
> 휴대폰에서는 데일리 팝업 노트와 지도가 나란히, 캘린더는 그 아래에 나옵니다.

### 상세 화면

- 사진 넘겨 보기, **방문 전 확인**(위치·일정, `지도에서 확인하기`), **혜택**(특전·굿즈·이벤트), **참고 웹사이트**.
- 제목 옆 **공유**(카카오톡·인스타그램·링크 복사)와 **팔로우** 스위치.
- 오른쪽 **리뷰** 탭: 다녀온 후기(별점 1~5)·기대평·답글. 내가 쓴 글은 `⋯` 에서 수정·삭제.
- 오른쪽 **수정하기** 탭: 누구나 고칠 수 있고, 잘못 고쳤으면 **되돌리기** 한 번으로 복구합니다.

### 등록하기 (화면 오른쪽 아래 코랄색 버튼)

1. **작품 · 캐릭터** 를 고릅니다 (목록에 없으면 새로 입력).
2. 공지 글이 있으면 **공지로 간편등록** → 공지를 붙여넣고 **읽어오기** 를 누르면 작품·카페명·주소·기간·캐릭터·특전·굿즈 칸이 자동으로 채워집니다.
3. 직접 넣을 때는 카페 정보 → 이미지 → 기간 → 특전·굿즈 순서로 한 단계씩 입력합니다. 주소는 **우편번호로 주소 찾기** 로 고르면 정확합니다.
4. 마지막 **등록 확인** 에서 내용을 한눈에 보고 **등록하기** 를 누르면 바로 지도에 올라갑니다.

> 전화번호·이메일·계좌번호·주민번호·카드번호가 들어 있으면 저장되지 않습니다.

## 3. 키 설정하기 (선택)

키가 **없어도** 앱은 돌아갑니다. 있으면 기능이 좋아집니다.

1. 예시 파일을 복사해 `.env` 를 만듭니다.
   ```bash
   copy .env.example .env      # Mac: cp .env.example .env
   ```
2. `.env` 를 메모장 등으로 열어 필요한 줄만 채우고, 앱을 다시 실행합니다.

| 키 | 있으면 좋아지는 것 | 받는 곳 |
| --- | --- | --- |
| `KAKAO_REST_API_KEY` | 주소 → **정확한 좌표** (없으면 동네 중심 좌표로 대략 표시) | https://developers.kakao.com → 내 애플리케이션 → 앱 키 |
| `KAKAO_JS_KEY` | 지도를 **카카오맵**으로 그리기, 카카오톡 카드 공유. 플랫폼 > Web 에 `http://localhost:8501` 등록 필요 | 위와 같은 곳 |
| `NOTION_TOKEN`, `NOTION_DATABASE_ID` | Notion 트래커 DB 의 새 행사를 자동으로 가져오기 | https://www.notion.so/my-integrations |
| `STORAGE_MODE=sheets` + Google 키 | 데이터를 Google Sheets 에 저장 (없으면 `data/` 폴더 JSON) | 아래 [Google Sheets 연결](#google-sheets-연결-선택) |

> `OPENAI_API_KEY` 는 이 저장소의 다른 앱(부록의 백로그 우선순위 생성기)에서만 씁니다. ANI:WHERE 의 간편등록은 키 없이 규칙으로 공지를 읽습니다.
>
> ⚠️ `.env` 에는 비밀 키가 들어갑니다. **절대 GitHub 에 올리지 마세요.** (`.gitignore` 에 이미 들어 있어 `git add .` 해도 빠집니다.)

## 4. 인터넷에 올리기 (Streamlit Cloud 배포)

내 GitHub 저장소를 연결하면 무료로 웹 주소가 생깁니다.

1. 이 저장소를 내 GitHub 계정으로 **Fork** 합니다 (오른쪽 위 `Fork` 버튼).
2. https://share.streamlit.io 에 GitHub 계정으로 로그인 → **Create app** → **Deploy a public app from GitHub**.
3. 저장소: `<내 아이디>/ANI-WHERE`, 브랜치: `main`, 파일: **`app_cafemap.py`** → **Deploy**.
4. 키가 필요하면 앱 화면의 **⋮ → Settings → Secrets** 에 `.env` 와 같은 형식으로 넣습니다.
   ```toml
   KAKAO_JS_KEY = "여기에 키"
   KAKAO_REST_API_KEY = "여기에 키"
   ```
   카카오맵을 쓰려면 카카오 개발자 콘솔 > 플랫폼 > Web 에 배포 주소(예: `https://ani-where.streamlit.app`)도 추가하세요.
5. 다른 사람도 보게 하려면 **Settings → Sharing** 에서 **Public** 으로 바꿉니다.
6. 이후 GitHub 에 `git push` 하면 몇 분 안에 자동으로 다시 배포됩니다.

> 배포 사이트에서는 키가 없으면 데이터가 서버의 `data/` 폴더에 저장되는데, 앱이 다시 시작되면 사라질 수 있습니다. 오래 보관하려면 Google Sheets 연결을 권장합니다.

## 5. 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| `'python' 은(는) ... 명령이 아닙니다` | Python 설치 때 `Add python.exe to PATH` 를 체크하지 않았습니다. 다시 설치하며 체크하세요 (Mac 은 `python3`) |
| `ModuleNotFoundError: No module named 'streamlit'` | 가상환경이 꺼져 있습니다. `.venv\Scripts\activate` (Mac: `source .venv/bin/activate`) 후 `pip install -r requirements.txt` |
| `activate` 가 막힘 (Windows) | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 한 번 실행 |
| `Port 8501 is already in use` | 이미 켜져 있습니다. 브라우저에서 http://localhost:8501 을 열거나, 다른 터미널의 앱을 `Ctrl + C` 로 끄세요 |
| 지도에 점만 있고 배경 지도가 안 나옴 | 배경 지도는 인터넷이 필요합니다. 연결을 확인하세요 |
| 카카오맵이 안 뜨고 기본 지도로 나옴 | 카카오 콘솔 > 플랫폼 > Web 에 지금 주소(`http://localhost:8501` 또는 배포 주소)를 등록했는지 확인 |
| 내 주변이 아니라 다른 지역이 먼저 나옴 | 브라우저 위치 권한을 허용하세요 (주소창 왼쪽 자물쇠 아이콘 → 위치). 데일리 팝업 노트 제목 옆 `?` 에 지금 상태가 나옵니다 |
| 코드를 고쳤는데 화면이 그대로 | `common/` 폴더의 파일을 고쳤다면 터미널에서 `Ctrl + C` 로 끄고 다시 `streamlit run app_cafemap.py` |

## 6. 더 알아보기 — 설계와 구조

### 왜 승인제를 뺐나

팝업 카페는 몇 주 안에 끝나고, 특전은 개시 첫 며칠에 소진되는 경우가 많습니다. 승인에 하루가 걸리면 정보 가치가 크게 떨어집니다. **콘텐츠 수명이 짧은 도메인에서는 정확도보다 속도가 우선**이라 판단했고, 정확도는 다음 세 가지로 지켰습니다.

| 장치 | 막는 것 |
| --- | --- |
| 입력 검증 | 날짜 역전, 이미 끝난 행사, 주소 없음, 좌표 못 찾음, 중복 등록 |
| 민감정보 차단 | 전화번호·이메일·계좌번호·주민번호·카드번호를 저장 전에 제거 |
| 되돌리기 | 수정·삭제가 덮어쓰기가 아니라 새 줄로 쌓여서 언제든 복구 가능 |

### 저장소 구조

Google Sheets(또는 로컬 JSON)에 **append-only** 로 쌓습니다. 기존 줄을 절대 지우거나 덮어쓰지 않습니다.

```
entry_id  revision  status    cafe_name
abc123    1         active    커피앤북 홍대점     ← 처음 등록
abc123    2         active    망가뜨린 이름       ← 누가 잘못 고침
abc123    3         active    커피앤북 홍대점     ← 되돌리기 (2번을 지우지 않고 3번을 쌓음)
```

마지막 revision 이 현재 상태, 그 직전이 되돌릴 대상입니다.

### Google Sheets 연결 (선택)

1. Google Cloud 에서 서비스 계정을 만들고 JSON 키를 내려받습니다
2. 구글 시트를 하나 만들고, 서비스 계정 이메일에 **편집 권한**을 줍니다
3. `.env` 에 채웁니다

```
STORAGE_MODE=sheets
GOOGLE_SERVICE_ACCOUNT_FILE=./service_account.json
GSHEET_KEY=<시트 URL 의 /d/ 와 /edit 사이 문자열>
```

연결에 실패해도 멈추지 않고 로컬 JSON 으로 자동 전환합니다.

### 지도 좌표

- 등록·수정 화면의 **📮 우편번호로 주소 찾기** 는 카카오 우편번호 서비스라 키 없이 바로 쓸 수 있습니다. 고른 주소의 좌표는 아래 순서로 찾습니다
- `KAKAO_REST_API_KEY` (카카오 개발자 콘솔 REST API 키) 가 있으면 카카오 로컬 API 로 **정확한 주소 좌표**를 찾습니다
- `KAKAO_JS_KEY` (JavaScript 키) 가 있으면 메인 지도를 **카카오맵**으로 그립니다. 콘솔 > 플랫폼 > Web 에 `http://localhost:8501` 을 등록해야 합니다. 없으면 기본 지도(Leaflet + OpenStreetMap)를 씁니다. 어느 지도든 아시아 밖으로는 이동할 수 없습니다
- 카카오 키가 없으면 `NAVER_MAPS_CLIENT_ID` / `NAVER_MAPS_CLIENT_SECRET`, `NAVER_SEARCH_CLIENT_ID` / `NAVER_SEARCH_CLIENT_SECRET` 로 네이버를 대신 씁니다
- 키가 없으면 내장 지역 사전(서울 구·동네, 전국 주요 시 약 120곳 + 시·도)에서 **그 동네 중심 좌표**를 씁니다. 화면에 "대략 위치" 로 표시됩니다
- "OO역 3번 출구 도보 5분" 같은 약식 주소 때문에도 이 경로가 필요합니다
- 아는 지역 이름이 없으면 **저장을 거부합니다.** 지도에 못 올릴 데이터를 쌓지 않기 위해서입니다

### 테스트용 샘플

| 파일 | 내용 |

### 지표

| 지표 | 보는 곳 |
| --- | --- |
| AI 추출 정확도 | 샘플 30건으로 프롬프트 v1 → v3 비교 (`CAFE_PROMPT_VERSION` 만 바꿔 재실행) |
| 사람이 손댄 필드 비율 | 확인 단계 화면에 바로 표시. 어떤 필드가 자주 틀리는지가 다음 개선 포인트 |

| 등록 1건 소요 시간 | 수동 입력 vs 붙여넣기, 초 단위 실측 |

### 알려진 한계

- 좌표 사전은 **근사값**입니다. 키 없이 돌리면 같은 동네 카페가 한 점에 겹칩니다. 정확한 위치가 필요하면 카카오 키를 넣으세요
- 지역 사전에 없는 중소도시는 저장이 거부됩니다. `common/geo.py` 의 `GAZETTEER` 에 추가하면 됩니다
- 로그인이 없어서 누가 고쳤는지는 남지 않습니다 (2차 프로젝트 범위)
- 배경 지도 타일은 인터넷이 필요합니다

## 부록 — 같은 저장소의 다른 앱: 백로그 우선순위 생성기

백로그 CSV와 이번 분기 KPI를 넣으면, **무엇을 먼저 할지 Top 10 + 각 항목의 근거 한 문장 + 이번 분기에 하지 않는 것과 그 이유**를 뽑아주는 도구입니다.

### 스티커 보드

AI가 낸 순위가 보드 위에 스티커로 깔립니다. 그대로 쓰지 않고 **직접 끌어서 조정**할 수 있습니다.

#### 템플릿 두 가지

| 템플릿 | 칸 | 쓰는 때 |
| --- | --- | --- |
| **3x3 우선순위 지정** | 영향도 3단계 × 공수 3단계 = 9칸 | 항목이 많고 단계를 세밀하게 나누고 싶을 때 |
| **영향 / 노력 매트릭스** | Do it now / next / 여유 있을 때 / 하지 않는다 = 4칸 | 회의에서 빠르게 합의할 때 |

#### 어떻게 동작하나

- 처음 위치는 **AI 점수(세로) × 공수(가로)** 로 자동 배치됩니다
- 스티커 색은 **연결된 KPI** 별로 다릅니다. 한 KPI에 일이 몰렸는지 한눈에 보입니다
- 스티커에 마우스를 올리면 **AI가 그 순위를 매긴 이유**가 뜹니다
- 칸마다 우선순위 등급(1순위 칸 ~ 9순위 칸)이 정해져 있습니다. 스티커를 옮기면 **칸 등급 + 칸 안에서의 위치** 로 최종 순위가 다시 계산됩니다
- **AI 결과로 되돌리기** 버튼으로 언제든 처음 배치로 돌아갑니다

#### 보드 위의 두 가지 선택

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| 제외 항목도 보드에 올리기 | 꺼짐 | 켜면 이번 분기에 빼기로 한 항목까지 보입니다. 위 칸으로 옮기면 되살아납니다 |
| 영향도를 이번 백로그 안에서 상대 평가 | 켜짐 | 점수는 최고점을 100으로 환산한 상대값이라, 고정 경계(34/67)를 쓰면 대부분 아래 칸에 몰립니다. 켜 두면 이번 백로그 안의 분위수로 나눕니다 |

#### 조정 결과로 나오는 지표

보드를 건드리면 세 숫자가 바뀝니다. **"AI를 어디까지 따랐는가"** 의 근거가 됩니다.

- **내가 옮긴 항목** — 상위 10건 중 AI 순위와 달라진 수
- **순위가 그대로인 항목** — AI 판단을 그대로 받아들인 수
- **AI 상위 10건과 겹침** — 구성 자체가 얼마나 유지됐는지

### 동작 방식

```
CSV 업로드
   ↓
guard.validate_backlog()      필수 컬럼 · id 중복 · 공수 숫자 검사
   ↓
guard.mask()                  전화번호 · 이메일 · 계좌번호를 가림
   ↓
ai.call_structured()          OpenAI 호출, JSON 스키마 강제, 실패 시 1회 재시도
   ↓  (실패하면)
priority.rule_based()         (KPI 가중치 ÷ 공수) 로 계산하는 대체 경로
   ↓
Top 10 + 근거 + 제외 목록
```

**재현성을 위해 `temperature=0`, `seed=42` 로 고정**했습니다. 동점일 때는 `id` 순으로 정렬해 대체 경로도 항상 같은 결과를 냅니다.

---

### 알려진 한계

- 규칙 기반 대체 경로는 단어 겹침으로 KPI를 고릅니다. "가입 신청서 임시 저장"처럼 설명에 `이탈` 이 들어가면 `신규 가입 전환` 대신 `해지율 감소` 로 붙을 수 있습니다. 화면에 "KPI 연결이 불확실해 점수를 낮춤"으로 표시됩니다.
- 공수(`effort_days`)는 사람이 입력한 값을 그대로 씁니다. 추정하지 않습니다.
- 우선순위 이력은 저장하지 않습니다 (2차 프로젝트 범위). 새로고침하면 보드 배치가 초기화됩니다.
- 보드 드래그는 HTML5 drag and drop 을 씁니다. 데스크톱 브라우저 기준이며 모바일 터치 드래그는 지원하지 않습니다.
- 보드의 "상대 평가" 를 켜면 영향도가 **이번 백로그 안에서의 상대 위치**를 뜻합니다. 다른 분기의 보드와 칸 위치를 직접 비교하면 안 됩니다.
