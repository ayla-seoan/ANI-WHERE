# ANI:WHERE — 애니 팝업 카페 지도

전국에서 열리는 애니메이션 캐릭터 팝업·콜라보 카페를 **지도 한 장**에 모으는 웹 앱입니다.
누구나 둘러볼 수 있고, **회원**(카카오·네이버·아이디 가입)은 북마크·리뷰·등록·수정을 하고 **내 캘린더**와 **알림**을 받습니다.
오늘 열린 팝업은 **데일리 팝업 노트**에, 궁금한 건 **ANI:WHERE에게 물어보기**로 찾습니다.

| | 주소 |
| --- | --- |
| 🌐 바로 써 보기 (배포된 사이트) | https://ani-where.streamlit.app |
| 📱 공개 웹 (폰에 설치되는 PWA) | https://ani-where.vercel.app |
| 💻 소스 코드 (GitHub) | https://github.com/ayla-seoan/ANI-WHERE |

> 설치 없이 구경만 하려면 위 **배포된 사이트**를 열면 됩니다. 내 컴퓨터에서 직접 실행해 보려면 아래 순서를 그대로 따라 하세요.

## 1차 프로젝트 (2026-10-28 ~ 11-16)

> **목표:** X·인스타·모음 사이트에 흩어진 애니 팝업·콜라보 카페를 지도 한 장에 모은다. 팝업은 몇 주면 끝나서 승인 없이 **누구나 바로 등록·수정**하고, 잘못 고친 것은 **되돌리기**로 바로잡는다.
> 첫 공개 10/28 → 마지막 기능 커밋 11/03 → 11/16 까지는 Notion 주간 자동 가져오기로 데이터만 쌓임.

| 영역 | 1차에서 만든 것 |
| --- | --- |
| 찾기 | 리스트(검색 · 작품 · 캐릭터 · 진행여부 · 날짜 필터, 정렬, 모바일 필터 시트), **지도보기**(데일리 팝업 노트 · 지도 · 내 캘린더 3단, 내 위치 기준 지역 순서) |
| 판단 | 상세 화면: 사진 넘겨 보기 · 방문 전 확인(위치 · 일정) · 혜택(특전 · 굿즈) · 참고 웹사이트(공식 공지 먼저, `recal.kr` 뒤로) · 팝업 소개 + 출처 보기 |
| 참여 | 리뷰(다녀온 후기 별점 · 기대평 · 답글, 사진 4장 · 확대 팝업, 평균 별점), 북마크 → 내 캘린더, 카카오톡 · 인스타 공유 |
| 등록 · 수정 | 등록하기 7단계(단계 표시줄) + **공지로 간편등록**(OpenAI 로 공지 글 → 칸 채우기, 실패하면 규칙 기반), 우편번호 주소 찾기, 누구나 수정 · **수정 이력 · 버전 되돌리기**(바뀐 칸만 표시) |
| 데이터 | **append-only 저장소**(로컬 JSON 또는 구글 시트, 수정 · 삭제도 새 줄), Notion 트래커 → 앱 가져오기(매주 월요일 GitHub Actions), 포스터 32장 |
| 안전 | 민감정보(전화번호 · 이메일 · 계좌 · 주민 · 카드) 저장 막기(`guard.py`), 모든 AI 호출에 규칙 기반 대체, 프롬프트는 파일 버전 관리(`common/prompts/`) |
| 사람 구분 | 로그인 없이 **접속 IP 로 만든 닉네임**(꾸밈말 + 캐릭터 이름 + `#네 글자`), 수정 기록에 수정한 사람 |
| 배포 | Streamlit Community Cloud — https://ani-where.streamlit.app |

**1차에서 남은 숙제 → 2차로 넘긴 것**

- 로그인이 없어 누가 썼는지 IP 닉네임으로만 구분 → 2차: 카카오 · 네이버 · 아이디 회원, 관리자
- 방문 전 정보가 빠진 팝업이 30% (기간 · 위치 · 공식 공지 중 하나 없음, 10/30 이전 60건 중 완결률 70.0%) → 2차 북극성 지표
- 원하는 팝업을 찾으려면 필터를 여러 번 만져야 함 → 2차: ANI:WHERE에게 물어보기(RAG)
- 데이터가 로컬 파일 · 시트라 동시에 쓰기 · 권한 관리가 약함 → 2차: Supabase + RLS
- 폰에서 현장에 갈 때 무거움 → 2차: 공개 웹(Next.js · PWA)
- 자동 테스트 · 지표 화면 없음 → 2차: e2e · `/stats` · MCP 서버

### 운영 구성 — 두 서비스를 함께 운영

| | Streamlit 앱 (`app_cafemap.py`) | 공개 웹 (`web/`, Next.js + PWA) |
| --- | --- | --- |
| 역할 | **참여**: 등록·수정·리뷰·북마크·로그인·물어보기·지표·관리자 | 같은 기능 전부 (등록·수정·되돌리기·삭제 요청·리뷰·사진·북마크·종 알림·물어보기·지표·관리자) + 폰에 설치 |
| 쓰기 | O (append-only) | O (서버 액션에서만, anon 키, append-only · 사진은 Supabase Storage `uploads`) |
| 배포 | Streamlit Community Cloud — https://ani-where.streamlit.app | Vercel — https://ani-where.vercel.app (Root Directory = `web`) |
| 로컬 | `streamlit run app_cafemap.py` → http://localhost:8501 | `cd web && npm run dev` → http://localhost:3000 |
| 데이터 | 같은 저장소 (`STORAGE_MODE`: local / supabase) | Supabase `popups_current` 뷰, 없으면 GitHub 의 `data/cafes.json` |

두 서비스는 같은 데이터·같은 계정(`aw_session`)·같은 알림 읽음 쿠키 모양을 쓴다. 웹은 Streamlit 으로 넘어가는 링크가 없다 — 웹에서 올린 사진은 https 주소로 저장돼 Streamlit 에서도 보인다 (`supabase/migrations/011_storage.sql` 을 먼저 적용).

### 2차에서 새로 생긴 것 실행해 보기

```bash
# 앱: 리스트 옆 '물어보기' 대화창, 지표는 주소 뒤에 /stats, 관리자 대시보드는 관리자 로그인 후 위 '관리자' 버튼
streamlit run app_cafemap.py          # http://localhost:8501/ask , /stats , /login

# 개발 도구 (테스트·MCP)
pip install -r requirements-dev.txt
python -m playwright install chromium
python scripts/qa_report.py           # 핵심 흐름 자동 테스트 (실제 data/ 는 건드리지 않음)
python -X utf8 scripts/eval_ask.py    # 물어보기 검색 정확도
python -X utf8 scripts/metrics_snapshot.py   # 지표 한 장 요약
python -X utf8 tests/mcp/check_server.py     # MCP 서버 확인

# 사람이 직접 커밋할 때도 커밋 전 검사 켜기 (한 번만)
git config core.hooksPath .githooks

# 공개 웹 (Next.js · PWA)
cd web && npm install && npm run dev  # 자세한 배포는 web/README.md
```

Supabase 연결은 [`db.md`](db.md) 6·8·10~12절 (SQL 001~010), 로그인 설정은 [`docs/login.md`](docs/login.md), 주간 브리핑 메일은 [`automation/README.md`](automation/README.md).

### 안정성 — 예외 처리 (평가표 '안정성')

실제로 터질 일을 먼저 적고, 하나씩 막았습니다. 시연 순서는 아래 표의 '보여 주는 법' 그대로입니다.

| 터질 일 | 막은 방법 | 보여 주는 법 | 코드 |
| --- | --- | --- | --- |
| **필터 결과 0건** | 빈 표 대신 "이 조건엔 행사가 없어요" + **조건 하나씩 풀기 버튼** (지역만 풀기 · 날짜 풀기 · 진행 여부 풀기 · 작품/캐릭터 풀기 · 검색어 지우기, 버튼마다 풀면 몇 곳인지) + 조건 모두 초기화 | 검색에 없는 말 입력 → '검색어 지우기 (N곳)' 누르기 | `_empty_state`, `_filter_view` |

#### 왜 만 14세 미만 가입을 막았나 (법 근거)

- **개인정보 보호법 제22조의2:** 만 14세 미만 아동의 개인정보를 처리하려면 **법정대리인(부모 등)의 동의**를 받아야 한다. 법이 '가입 금지'를 요구하는 것은 아니고, 받으려면 법정대리인 동의 절차가 있어야 한다.
- 선택지는 ① 법정대리인 동의 절차를 만들어 아이도 받기, ② **만 14세 미만은 가입을 받지 않기** 두 가지다. ANI:WHERE 는 법정대리인 확인 절차가 없으므로 **② 를 골랐다** — 지금 할 수 있는 유일한 합법적 방법.
- 애니·서브컬처 팝업 서비스는 중학생 이하 유입 가능성이 실제로 높다. "성인 대상" 이라고 해도 실제로 가입되면 운영자 책임이라, 고지만 하지 않고 **[필수] 확인 체크를 통과해야만 가입**되게 했다.
- 로그인 없이 둘러보기(목록·지도·상세·물어보기)는 누구나 된다. 이때는 개인정보를 받지 않는다.
- **남는 한계:** 체크는 본인이 스스로 확인하는 방식이라 거짓으로 체크하면 막을 수 없다. 운영 중에 14세 미만 가입을 알게 되면 그 정보를 지워야 하는데, 관리자가 바로 지우는 기능은 아직 없다 (지금은 탈퇴로만 처리). → 공개 전 보완: 법정대리인 동의 절차 또는 관리자 강제 탈퇴·파기 기능.
- (법 조항을 바탕으로 정리한 내용이며 법률 자문이 아니다. 정식 공개 전에 개인정보보호위원회 안내나 전문가 확인을 받는다.)

- **화면 다듬기 · 속도 (11/19 오후):** 내 캘린더 북마크 · 다녀온 팝업은 10건까지 보이고 '+N건 더보기' 로 10건씩. 공개 웹 리스트에도 앱과 같은 '북마크' 버튼(내가 북마크한 팝업만), 북마크는 검색 조건이 아니라 검색 아이콘 옆 숫자에 세지 않음(두 사이트). 물어보기 칸은 답 카드 · 필터가 생겨도 넓어지지 않고, 대화가 길 때 마우스로 내려도 마지막 질문으로 되돌아가지 않음(Streamlit). 페이지 이동 속도: Vercel 함수를 서울(icn1)로 옮겨 Supabase(서울)와 같은 곳에서 돌고, 레이아웃 · 상세의 DB 읽기를 동시에, 링크를 누르는 즉시 맨 위 진행 막대. Streamlit 은 지도보기에 들어갈 때 위치를 다시 묻지 않고(다시 그리기 2번 줄임), 카드를 누르면 한 번만 그림
- **블로그 후기 저장 (11/19):** 찾은 블로그 글을 DB(`blog_posts`, 013)에 저장해 두고 두 사이트가 바로 보여 준다. 네이버는 팝업마다 하루 한 번만 물어 새 글만 더한다(처음 정확도순 → 이후 최신순). 한도에 걸려도 저장된 글은 보인다. 그 밖에 홈 '북마크 팝업' 동그라미의 지역 배지를 민트(#56C2A7)로, Streamlit 수정하기 · 리뷰 수정의 사진 미리보기가 파일을 못 찾으면 앱이 멈추던 문제(MediaFileStorageError)를 '(파일 없음)' 표시로
- **공개 웹 지도 · 리스트 · 관리자 (11/19 저녁):** 지도로 보기는 위치를 허용하면 앱처럼 내 주변에서 시작하고(가까운 팝업 3곳이 들어오게, 파란 점) 데일리 팝업 노트도 가까운 지역부터. 위치는 브라우저 안에서만 쓰고 저장하지 않는다. 지도 아래 '팝업 카페 N곳' 줄은 뺐다. 리스트 지역 고르기는 여러 곳 함께(앱 multiselect 와 같게). 관리자 '고른 주 현황' 포스터가 제대로 보이게(cover), 종료 칸은 눌리지 않는 정보 카드, 지난 주를 고르면 '종료된 팝업은 다음 주 월요일에 삭제돼 보이지 않을 수 있어요' 회색 안내(두 사이트). Streamlit 칸반 '더보기' 버튼이 칸 테두리에 겹치던 것 여백
- **지도 다듬기 (11/19 밤):** 두 사이트 지도 오른쪽 아래 **'내 위치' 버튼**(누르면 위치를 묻고 내 자리로 확대 + 파란 점, 거절하면 권한 안내. 위치는 화면 안에서만 쓰고 저장 · 전송하지 않음). 공개 웹 지도로 보기 아래 팝업 카드 목록 · 더보기는 뺐다. Streamlit 지도에서 누른 핀은 크게 + 분홍(창을 닫으면 원래대로), 대체 지도(Leaflet)도 핀을 누르면 목록 창. Streamlit 홈 주간 칸 '+N건 더보기' · 관리자 지난 주 삭제 안내는 가운데 정렬
- **기간 종료 팝업 (11/19 바뀜):** 매일 지도·리스트에서 내리고('기간 종료' 기록), **월~일 한 주가 지나 다음 주 월요일 00:10 이 되면 DB 에서도 지운다** — 지난주까지 기간이 끝났거나 삭제 요청 승인으로 내린 팝업의 모든 기록과 그 리뷰 · 북마크 · 삭제 요청 (`supabase/migrations/012`, Supabase pg_cron). 사진 파일은 매일 가져오기 작업이 '어느 기록도 쓰지 않는' 것만 지운다 (`scripts/storage_sweep.py`). 되돌릴 수 없고, 지운 팝업은 /stats 예전 완결률 · 간트 · 내 캘린더 지난 달 · 다녀온 팝업에서도 빠진다 (사용자 결정). 기간이 남았는데 내린 팝업은 Notion 번호만 남겨 다시 가져오지 않는다 (`purged_popups`)
- **품질:** e2e 14개 테스트(가입·검색과 0건 완화·상세·북마크·리뷰 개인정보 차단·모바일·손님 제한·등록 제한·로그아웃 유지·새 계정 북마크 비어 있음·북마크 팝업·홈·내 리뷰 사진 추가와 삭제·디자인 시스템 페이지), 커밋 전 검사 훅, RLS. 공개 웹은 `npm run test:ask` · `test:auth`(Python ↔ TS 로그인 쿠키 호환) · `web/scripts/e2e_*.py` 5종(로컬 데이터로만, 실제 DB 를 건드리지 않음)

## 1. 내 컴퓨터에서 실행하기 (처음부터 따라 하기)

> ⏱ 처음이라도 10분이면 됩니다. **API 키가 하나도 없어도 앱 전체가 돌아갑니다.**

### 1-1. 준비물 설치 (한 번만)

| 준비물 | 받는 곳 | 확인 방법 (터미널에 입력) |
| --- | --- | --- |
| **Python 3.10 이상** | https://www.python.org/downloads/ | `python --version` (Mac 은 `python3 --version`) |
| **Git** | https://git-scm.com/downloads | `git --version` |

- **Windows:** Python 설치 첫 화면에서 **`Add python.exe to PATH`** 를 꼭 체크하세요.
- **터미널 여는 법:** Windows 는 시작 메뉴에서 `PowerShell`, Mac 은 `Spotlight(⌘+Space)` → `터미널`.

### 1-2. 코드 내려받기

터미널에 한 줄씩 입력합니다.

```bash
git clone https://github.com/ayla-seoan/ANI-WHERE.git
cd ANI-WHERE
```

> Git 이 어렵다면 GitHub 페이지의 초록색 **Code → Download ZIP** 으로 받아 압축을 풀고, 그 폴더에서 터미널을 열어도 됩니다.

### 1-3. 가상환경 만들고 패키지 설치

가상환경은 이 프로젝트 전용 파이썬 공간입니다. 다른 프로그램과 섞이지 않게 해 줍니다.

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Mac / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- 성공하면 터미널 맨 앞에 `(.venv)` 가 붙습니다.
- Windows 에서 `activate` 가 "스크립트를 실행할 수 없습니다" 로 막히면, 먼저 아래를 한 번 입력하고 다시 해 보세요.
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

### 1-4. 실행

```bash
streamlit run app_cafemap.py
```

- 브라우저가 자동으로 **http://localhost:8501** 을 엽니다. 안 열리면 주소창에 직접 입력하세요.
- 처음 열면 `data/` 폴더의 예시 팝업들이 리스트로 보입니다.
- 끌 때는 터미널에서 **`Ctrl + C`**.

### 1-5. 다음에 다시 실행할 때

```bash
cd ANI-WHERE
.venv\Scripts\activate          # Mac: source .venv/bin/activate
streamlit run app_cafemap.py
```

### 1-6. 최신 코드로 업데이트

```bash
git pull
pip install -r requirements.txt   # 패키지가 바뀌었을 수 있어 한 번 더
```

### 홈 (첫 화면, 11/18)

| 칸 | 내용 |
| --- | --- |
| **북마크 팝업** (`?` 설명) | 내가 북마크한 진행 중·예정 팝업이 인스타 스토리처럼 동그라미로. 위에 지역, 아래 작품 이름, **누르면 그 팝업 상세**. 맨 앞 **최애 추가하기** → 포스터를 눌러 여러 팝업을 한 번에 북마크(검색칸 있음). 손님은 로그인 화면으로 |
| **실시간 인기 급상승 랭킹** | 최근 7일 북마크 × 2 + 리뷰·답글 수 (같으면 전체 기간 점수, 화면 조회 수는 세지 않음) 1~5위. 왼쪽 큰 배너(‹ › · 5초마다 넘어감 · 오른쪽 아래 점), 오른쪽 1~5위 목록 — **목록을 누르면 배너가 그 순위로**, **배너를 누르면 상세** |
| **따끈따끈 신규 등록 팝업** | 처음 등록한 시각이 늦은 순 12곳, 지역 버튼, 옆으로 넘기기, `더보기` → 리스트 최신순 |
| **이번 주에 끝나는 팝업** | 월~일 주간 캘린더(오늘 칸 민트). 요일마다 2곳 + `+N건 더보기`(그 칸에서 펼침). 휴대폰은 월~일을 위에서 아래로, 작은 그림 + 옆 글자 |
| **사전예약 팝업** | 태그·특전·소개에 '사전 예약'이 있고 **아직 열기 전**인 팝업 (보라색 `사전예약 D-n`). `더보기` → 리스트에 '사전예약 팝업만 보는 중' 칩 (누르면 풀림) |
| **꿀팁 가득! 실시간 후기 모음** | 최신 리뷰 12개, **사진 있는 리뷰가 먼저**. 팝업(포스터·상태·지역) + 리뷰(사진·닉네임·날짜·별점·본문·사진 2장), 누르면 그 팝업 |

- 줄은 마우스로 끌거나 양옆 `‹ ›` 로 넘깁니다 (상세 아래 추천 줄도 같음).

| 왼쪽 — 데일리 팝업 노트 | 가운데 — 지도 | 오른쪽 — 내 캘린더 |
| --- | --- | --- |
| (오른쪽 칸은 물어보기 창) 오늘(‹ › 로 날짜 이동) 열려 있는 팝업. 지역도 ‹ › 로 넘깁니다. **내 위치에서 가까운 지역부터** 보여 줍니다 (제목 옆 `?` 에 안내). 목록을 누르면 **지도가 그 자리로 이동해 미리보기**가 뜹니다 | 처음엔 **내 주변**이 보입니다. 점을 한 번 누르면 미리보기, **한 번 더 누르면 상세**. 오른쪽 위에서 `밝은 회색 / 컬러 / 다크` 지도 모양을 고릅니다 (세 가지 모두 한글 지명) | **북마크한 팝업**이 날짜에 막대로 표시됩니다 (연속된 날은 한 막대). 막대에 마우스를 올리면 미리보기, 아래에 **곧 있는 팝업** 목록. 제목 옆 `?` 에 안내, `이번달` 로 이번 달로 돌아오기. 제목 아래 회색 글씨는 **내 닉네임** |

> 📍 처음 지도보기를 열면 브라우저가 **위치 권한**을 묻습니다. 허용하면 내 주변이 먼저 나옵니다. 위치는 지역 순서·지도 처음 화면을 정하는 데만 쓰고 저장하지 않습니다.
> 휴대폰에서는 데일리 팝업 노트와 지도가 나란히(노트는 지도 높이만큼, 안에서 스크롤), 캘린더는 그 아래에 나옵니다.

### 상세 화면

- 사진 넘겨 보기, **방문 전 확인**(위치·일정, `지도에서 확인하기`), **혜택**(특전·굿즈·이벤트), **참고 웹사이트**, **팝업 소개**.
  - 참고 웹사이트는 공식 공지·주최 링크가 먼저, `recal.kr` 같은 모음 사이트는 맨 뒤에 나옵니다 (다른 사이트가 없으면 그대로 첫 번째).
  - 팝업 소개는 참고 웹사이트 아래 회색 상자에 나옵니다. `[체험]` 같은 머리말은 민트색 굵은 글씨, 출처가 있으면 상자 오른쪽 아래 **출처 보기** 버튼(새 탭). 소개가 없는 팝업은 이 칸이 나오지 않습니다.
- 작품 이름 오른쪽 **공유**(누르면 카카오톡·인스타그램·링크 복사가 펼쳐짐)와 **북마크** 아이콘.
- 오른쪽 **리뷰** 탭:
  - 종류: 다녀온 후기(별점 1~5) · 기대평 · 기타, 그리고 답글.
  - 별점을 준 다녀온 후기가 있으면 목록 위에 **평균 별점**(숫자 + 평균만큼 채운 별 + "다녀온 후기 N개 평균")이 나옵니다. 답글·기대평은 세지 않습니다.
  - **다녀온 후기는 별점만 골라도, 사진만 붙여도 등록**됩니다. 등록된 별점은 글 위 줄에 포인트 색(민트)으로 반짝이며 보입니다.
  - `+ 사진 첨부` 를 누르면 사진을 붙일 수 있습니다 (최대 4장, 한 장 10MB).
  - 리뷰에 붙은 사진을 누르면 **확대 팝업**이 열립니다: `+` `−` `⟲` 버튼·마우스 휠·사진 클릭으로 확대, 끌어서 이동, 여러 장이면 `‹ ›`, `×` 나 Esc·바깥 클릭으로 닫기.
  - 내가 쓴 글만 `⋯` 에서 **수정 · 삭제**. 다른 사람 글에는 `⋯` 가 없습니다. 관리자는 모든 리뷰를 `삭제 (관리자)` — 사유를 적으면 쓴 회원에게 알림이 갑니다 (11/18).
  - 리뷰에는 쓴 사람의 **프로필 사진 + 닉네임**만 보입니다 (사진이 없으면 기본 그림).
- 리뷰 쓰기 칸 아래 **리뷰 후기 (N) / 블로그 후기 (N)** 탭:
  - 블로그 후기 = 네이버 블로그 검색(NAVER API HUB) 결과 최대 15개. 제목·요약·블로거·날짜·대표 사진, 누르면 원문 새 탭. 위에 "참고로만" 안내.
  - 작품 이름과 매장·동네 이름이 함께 들어간 글, 팝업 시작 30일 전부터 쓴 글만. 같은 팝업은 하루 한 번만 검색.
  - **호출 한도:** 한 달 30,000번이 되면 더 부르지 않습니다 (블로그 후기는 그달엔 안 보임). 호출 수는 Supabase `api_usage` 표(010)에 25번마다 기록, 읽지 못하면 안전하게 부르지 않음.
- 오른쪽 **수정하기** 탭: 회원이면 누구나 고칠 수 있습니다. 글자 입력칸 오른쪽 `×` 로 내용을 한 번에 지울 수 있습니다. 맨 아래 `삭제 요청`(일반 회원) / `지도에서 내리기`(관리자).
  - 아래 **수정 이력** 을 펼치면 기록이 카드로 쌓여 있습니다 (맨 위가 지금 내용).
    - 기록마다 번호·시각·방법(직접 수정·AI 자동 수집·되돌리기 등)·**수정한 사람 닉네임**. 닉네임 기능 전 기록은 `닉네임 기록 전`.
    - 처음 등록한 기록만 카페·기간·주소를 다 보여 주고, 그다음부터는 **바뀐 칸만 `이전 → 이후`** 로 보여 줍니다. 사진은 `포스터 삭제/추가/변경`, `이미지 N장 삭제/추가` 로 나옵니다.
    - 원하는 기록의 **이 버전으로 돌아가기** 를 누르면 그 내용으로 돌아갑니다 (기존 기록은 지우지 않고 새 기록으로 쌓임).
- 맨 아래 추천 줄 (11/18, 제목 옆 `?` 설명): **비슷한 팝업**(같은 작품의 다른 지역 지점 → 같은 작품의 다른 행사, 끝난 것 빼고) · **이 근처 다른 팝업**(30km 안 가까운 순, 같은 건물이면 '같은 건물'). 카드 오른쪽 위에 지역.
- 리뷰를 **고칠 때 사진을 새로 붙이거나 뺄 수 있습니다** (원래 사진이 없었어도, 최대 4장).
- 목록으로 돌아갈 때는 위 메뉴바의 `리스트로 보기`·`지도로 보기` 탭이나 로고(→ 홈)를 누릅니다.

### 등록하기 (화면 오른쪽 아래 코랄색 `+` 버튼, 회원만)

1. **작품 · 캐릭터** 를 고릅니다 (목록에 없으면 새로 입력).
2. 공지 글이 있으면 **공지로 간편등록** → 공지를 붙여넣고 **읽어오기** 를 누르면 작품·카페명·주소·기간·캐릭터·특전·굿즈 칸이 자동으로 채워지고, 붙여넣은 공지 전체는 **팝업 소개** 칸에 들어갑니다 (고칠 수 있음).
3. 직접 넣을 때는 카페 정보 → 이미지 → 기간 → 특전·굿즈 → **팝업 소개**(비워 둬도 됨) 순서로 한 단계씩 입력합니다. 주소는 **우편번호로 주소 찾기** 로 고르면 정확합니다.
   - 위쪽 **단계 표시줄**에 7단계가 동그라미로 이어져 보입니다: 끝난 단계는 체크, 지금 단계는 민트색으로 강조 (휴대폰은 지금 단계 이름만).
4. 마지막 **등록 확인** 에서 내용을 한눈에 보고 **등록하기** 를 누르면 바로 지도에 올라갑니다.
5. 그만두려면 위 메뉴바의 탭이나 로고를 누릅니다 (메인과 같은 메뉴바).
6. 글자 입력칸 오른쪽 `×` 로 내용을 한 번에 지울 수 있습니다.

> 전화번호·이메일·계좌번호·주민번호·카드번호가 들어 있으면 저장되지 않습니다.

### Notion 트래커에서 팝업 가져오기

- Notion DB 는 예약 작업 **'애니 팝업·콜라보 매일 수집'** 이 매일 오전 8:00 에 RE:CAL 등에서 행사를 모아 채웁니다 (행사 × 지점 = 1행).
- 그 뒤 **매일 오전 8:40** GitHub Actions('Notion 매일 가져오기')가 Notion 을 직접 읽어 앱 데이터에 넣고 깃에 올립니다 → 배포 사이트가 자동으로 갱신됩니다. 저장소 Secret `NOTION_TOKEN` 이 필요합니다 (만드는 법은 아래 문서).
- `.env` 에 `NOTION_TOKEN` 이 있으면 메인 화면을 열 때(최대 1시간에 한 번)도 Notion '🎀 애니 팝업·콜라보 트래커' DB 에서 **검수상태가 '검토 완료'** 인 새 행사를 가져옵니다.
- 같은 작품·겹치는 기간·가까운 위치의 팝업이 이미 있으면 새로 만들지 않습니다. 포스터 이미지도 함께 내려받습니다.
- Notion 의 **팝업소개** 는 상세 화면의 팝업 소개로, **소개출처** 는 소개 상자 오른쪽 아래 **출처 보기** 버튼으로 들어갑니다. 소개는 Notion 기준으로 맞추되(바뀌면 바꾸고 지우면 비움), 사람이 앱에서 쓴 소개는 덮어쓰지 않습니다. 전화번호·이메일이 든 줄은 빼고 저장합니다.
- 지점은 Notion 이 이미 행마다 나눠 두므로 행 그대로 가져옵니다 ('지점' 칸은 형제 지점 목록).
- 이렇게 들어온 팝업은 수정 이력에 방법 **AI 자동 수집**, 수정한 사람 **AI** 로 남습니다.
- 주간 수집 규칙(무엇을 모으는지, 링크 4칸, 팝업소개 형식, 검수상태)과 앱 가져오기 규칙(칸별 규칙, 같은 팝업 판단 순서, 알려진 한계)은 [`docs/notion-import.md`](docs/notion-import.md) 에 정리했습니다.

## 3. 키 설정하기 (선택)

키가 **없어도** 앱은 돌아갑니다. 있으면 기능이 좋아집니다.

1. 예시 파일을 복사해 `.env` 를 만듭니다.
   ```bash
   copy .env.example .env      # Mac: cp .env.example .env
   ```
2. `.env` 를 메모장 등으로 열어 필요한 줄만 채우고, 앱을 다시 실행합니다.

| 키 | 있으면 좋아지는 것 | 받는 곳 |
| --- | --- | --- |
| `KAKAO_REST_API_KEY` | 주소 → **정확한 좌표** (없으면 동네 중심 좌표로 대략 표시) | https://developers.kakao.com → 내 애플리케이션 → 앱 키 |
| `KAKAO_JS_KEY` | 지도를 **카카오맵**으로 그리기, 카카오톡 카드 공유. 플랫폼 > Web 에 `http://localhost:8501` 등록 필요 | 위와 같은 곳 |
| `NOTION_TOKEN`, `NOTION_DATABASE_ID` | Notion 트래커 DB 의 새 행사를 자동으로 가져오기 | https://www.notion.so/my-integrations |
| `STORAGE_MODE=sheets` + Google 키 | 데이터를 Google Sheets 에 저장 (없으면 `data/` 폴더 JSON) | 아래 [Google Sheets 연결](#google-sheets-연결-선택) |

> `OPENAI_API_KEY` 는 이 저장소의 다른 앱(부록의 백로그 우선순위 생성기)에서만 씁니다. ANI:WHERE 의 간편등록은 키 없이 규칙으로 공지를 읽습니다.
>
> ⚠️ `.env` 에는 비밀 키가 들어갑니다. **절대 GitHub 에 올리지 마세요.** (`.gitignore` 에 이미 들어 있어 `git add .` 해도 빠집니다.)

## 4. 인터넷에 올리기 (Streamlit Cloud 배포)

내 GitHub 저장소를 연결하면 무료로 웹 주소가 생깁니다.

1. 이 저장소를 내 GitHub 계정으로 **Fork** 합니다 (오른쪽 위 `Fork` 버튼).
2. https://share.streamlit.io 에 GitHub 계정으로 로그인 → **Create app** → **Deploy a public app from GitHub**.
3. 저장소: `<내 아이디>/ANI-WHERE`, 브랜치: `main`, 파일: **`app_cafemap.py`** → **Deploy**.
4. 키가 필요하면 앱 화면의 **⋮ → Settings → Secrets** 에 `.env` 와 같은 형식으로 넣습니다.
   ```toml
   KAKAO_JS_KEY = "여기에 키"
   KAKAO_REST_API_KEY = "여기에 키"
   ```
   카카오맵을 쓰려면 카카오 개발자 콘솔 > 플랫폼 > Web 에 배포 주소(예: `https://ani-where.streamlit.app`)도 추가하세요.
5. 다른 사람도 보게 하려면 **Settings → Sharing** 에서 **Public** 으로 바꿉니다.
6. 이후 GitHub 에 `git push` 하면 몇 분 안에 자동으로 다시 배포됩니다.

> 배포 사이트에서는 키가 없으면 데이터가 서버의 `data/` 폴더에 저장되는데, 앱이 다시 시작되면 사라질 수 있습니다. 오래 보관하려면 Google Sheets 연결을 권장합니다.

## 5. 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| `'python' 은(는) ... 명령이 아닙니다` | Python 설치 때 `Add python.exe to PATH` 를 체크하지 않았습니다. 다시 설치하며 체크하세요 (Mac 은 `python3`) |
| `ModuleNotFoundError: No module named 'streamlit'` | 가상환경이 꺼져 있습니다. `.venv\Scripts\activate` (Mac: `source .venv/bin/activate`) 후 `pip install -r requirements.txt` |
| `activate` 가 막힘 (Windows) | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 한 번 실행 |
| `Port 8501 is already in use` | 이미 켜져 있습니다. 브라우저에서 http://localhost:8501 을 열거나, 다른 터미널의 앱을 `Ctrl + C` 로 끄세요 |
| 지도에 점만 있고 배경 지도가 안 나옴 | 배경 지도는 인터넷이 필요합니다. 연결을 확인하세요 |
| 카카오맵이 안 뜨고 기본 지도로 나옴 | 카카오 콘솔 > 플랫폼 > Web 에 지금 주소(`http://localhost:8501` 또는 배포 주소)를 등록했는지 확인 |
| 내 주변이 아니라 다른 지역이 먼저 나옴 | 브라우저 위치 권한을 허용하세요 (주소창 왼쪽 자물쇠 아이콘 → 위치). 데일리 팝업 노트 제목 옆 `?` 에 지금 상태가 나옵니다 |
| 내 캘린더가 비어 있음 | 북마크한 팝업만 보입니다. 리스트나 상세에서 북마크 아이콘을 눌러 보세요 |
| 배포 사이트에 새 팝업·로고가 안 보임 | `data/`·`static/` 파일도 GitHub 에 올렸는지 확인하세요. Streamlit Cloud 는 GitHub 에 있는 파일로만 다시 배포합니다 |
| 수정 이력에 `닉네임 기록 전` 이 보임 | 수정한 사람을 저장하기 전에 생긴 기록이라 이름이 없습니다. 이후 수정부터 닉네임이 남습니다 |
| 닉네임이 예전과 다름 | 닉네임 규칙이 '꾸밈말 + 캐릭터 이름' 으로 바뀌었습니다. `#네 글자` 가 같으면 예전 글도 그대로 내 글로 고치고 지울 수 있습니다 |
| 코드를 고쳤는데 화면이 그대로 | `common/` 폴더의 파일을 고쳤다면 터미널에서 `Ctrl + C` 로 끄고 다시 `streamlit run app_cafemap.py` |

## 6. 더 알아보기 — 설계와 구조

### 왜 승인제를 뺐나

팝업 카페는 몇 주 안에 끝나고, 특전은 개시 첫 며칠에 소진되는 경우가 많습니다. 승인에 하루가 걸리면 정보 가치가 크게 떨어집니다. **콘텐츠 수명이 짧은 도메인에서는 정확도보다 속도가 우선**이라 판단했고, 정확도는 다음 세 가지로 지켰습니다.

| 장치 | 막는 것 |
| --- | --- |
| 입력 검증 | 날짜 역전, 이미 끝난 행사, 주소 없음, 좌표 못 찾음, 중복 등록 |
| 민감정보 차단 | 전화번호·이메일·계좌번호·주민번호·카드번호를 저장 전에 제거 |
| 되돌리기 | 수정·삭제가 덮어쓰기가 아니라 새 줄로 쌓여서 원하는 버전으로 언제든 복구 가능 |
| 수정한 사람 | 기록마다 IP 기반 닉네임(`editor`)을 남겨 누가 고쳤는지 보임 |

### 저장소 구조

Google Sheets(또는 로컬 JSON)에 **append-only** 로 쌓습니다. 기존 줄을 절대 지우거나 덮어쓰지 않습니다.

```
entry_id  revision  status    cafe_name         source            editor
abc123    1         active    커피앤북 홍대점     직접 등록          졸린 고죠 사토루#a3f9   ← 처음 등록
abc123    2         active    망가뜨린 이름       직접 수정          길 잃은 루피#9c01      ← 누가 잘못 고침
abc123    3         active    커피앤북 홍대점     1번째로 되돌리기    졸린 고죠 사토루#a3f9   ← 1번 버전으로 (2번을 지우지 않고 3번을 쌓음)
```

마지막 revision 이 현재 상태입니다. 수정 이력에서 고른 버전의 내용을 그대로 새 줄로 쌓아 되돌립니다 (`storage.restore`).

### Google Sheets 연결 (선택)

1. Google Cloud 에서 서비스 계정을 만들고 JSON 키를 내려받습니다
2. 구글 시트를 하나 만들고, 서비스 계정 이메일에 **편집 권한**을 줍니다
3. `.env` 에 채웁니다

```
STORAGE_MODE=sheets
GOOGLE_SERVICE_ACCOUNT_FILE=./service_account.json
GSHEET_KEY=<시트 URL 의 /d/ 와 /edit 사이 문자열>
```

연결에 실패해도 멈추지 않고 로컬 JSON 으로 자동 전환합니다.

### 지도 좌표

- 등록·수정 화면의 **📮 우편번호로 주소 찾기** 는 카카오 우편번호 서비스라 키 없이 바로 쓸 수 있습니다. 고른 주소의 좌표는 아래 순서로 찾습니다
- `KAKAO_REST_API_KEY` (카카오 개발자 콘솔 REST API 키) 가 있으면 카카오 로컬 API 로 **정확한 주소 좌표**를 찾습니다
- `KAKAO_JS_KEY` (JavaScript 키) 가 있으면 메인 지도를 **카카오맵**으로 그립니다. 콘솔 > 플랫폼 > Web 에 `http://localhost:8501` 을 등록해야 합니다. 없으면 기본 지도(Leaflet + OpenStreetMap)를 씁니다. 어느 지도든 아시아 밖으로는 이동할 수 없습니다
- 카카오 키가 없으면 `NAVER_MAPS_CLIENT_ID` / `NAVER_MAPS_CLIENT_SECRET`, `NAVER_SEARCH_CLIENT_ID` / `NAVER_SEARCH_CLIENT_SECRET` 로 네이버를 대신 씁니다
- 키가 없으면 내장 지역 사전(서울 구·동네, 전국 주요 시 약 120곳 + 시·도)에서 **그 동네 중심 좌표**를 씁니다. 화면에 "대략 위치" 로 표시됩니다
- "OO역 3번 출구 도보 5분" 같은 약식 주소 때문에도 이 경로가 필요합니다
- 아는 지역 이름이 없으면 **저장을 거부합니다.** 지도에 못 올릴 데이터를 쌓지 않기 위해서입니다

### 알려진 한계

- 좌표 사전은 **근사값**입니다. 키 없이 돌리면 같은 동네 카페가 한 점에 겹칩니다. 정확한 위치가 필요하면 카카오 키를 넣으세요
- 지역 사전에 없는 중소도시는 저장이 거부됩니다. `common/geo.py` 의 `GAZETTEER` 에 추가하면 됩니다
- 비밀번호 찾기가 없습니다 (이메일·전화번호를 받지 않아서). 잊으면 새로 가입해야 합니다
- 알림 '읽음' 표시는 브라우저 쿠키에 남습니다. 다른 기기에서는 다시 '새 알림'으로 보입니다
- 만 14세 미만 법정대리인 동의 절차는 범위에서 뺐습니다 (가입 화면의 확인 체크만). 공개 전 보완 필요
- 직접 올린 프로필·리뷰 사진은 앱 서버 폴더에 저장돼서 Streamlit Cloud 를 다시 시작하면 사라질 수 있습니다 (그때는 기본 그림)
- 배경 지도 타일은 인터넷이 필요합니다
- 속도: Supabase 는 서버가 처음 뜰 때 한 번 불러와 기억합니다. 앱에서 등록·수정·리뷰·북마크를 저장하면 그 표는 바로 갱신되고, 매일 08:45(Notion 매일 가져오기 뒤) 이후 첫 접속에서 새로 불러옵니다. Supabase 화면에서 직접 고쳤다면 관리자 대시보드의 **데이터 새로 불러오기** (또는 30분 뒤 자동). 설정: `STORAGE_CACHE_SECONDS`(기본 1800) · `STORAGE_REFRESH_AT`(기본 08:45)

### 스티커 보드

AI가 낸 순위가 보드 위에 스티커로 깔립니다. 그대로 쓰지 않고 **직접 끌어서 조정**할 수 있습니다.

#### 템플릿 두 가지

| 템플릿 | 칸 | 쓰는 때 |
| --- | --- | --- |
| **3x3 우선순위 지정** | 영향도 3단계 × 공수 3단계 = 9칸 | 항목이 많고 단계를 세밀하게 나누고 싶을 때 |
| **영향 / 노력 매트릭스** | Do it now / next / 여유 있을 때 / 하지 않는다 = 4칸 | 회의에서 빠르게 합의할 때 |

#### 어떻게 동작하나

- 처음 위치는 **AI 점수(세로) × 공수(가로)** 로 자동 배치됩니다
- 스티커 색은 **연결된 KPI** 별로 다릅니다. 한 KPI에 일이 몰렸는지 한눈에 보입니다
- 스티커에 마우스를 올리면 **AI가 그 순위를 매긴 이유**가 뜹니다
- 칸마다 우선순위 등급(1순위 칸 ~ 9순위 칸)이 정해져 있습니다. 스티커를 옮기면 **칸 등급 + 칸 안에서의 위치** 로 최종 순위가 다시 계산됩니다
- **AI 결과로 되돌리기** 버튼으로 언제든 처음 배치로 돌아갑니다

#### 보드 위의 두 가지 선택

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| 제외 항목도 보드에 올리기 | 꺼짐 | 켜면 이번 분기에 빼기로 한 항목까지 보입니다. 위 칸으로 옮기면 되살아납니다 |
| 영향도를 이번 백로그 안에서 상대 평가 | 켜짐 | 점수는 최고점을 100으로 환산한 상대값이라, 고정 경계(34/67)를 쓰면 대부분 아래 칸에 몰립니다. 켜 두면 이번 백로그 안의 분위수로 나눕니다 |

#### 조정 결과로 나오는 지표

보드를 건드리면 세 숫자가 바뀝니다. **"AI를 어디까지 따랐는가"** 의 근거가 됩니다.

- **내가 옮긴 항목** — 상위 10건 중 AI 순위와 달라진 수
- **순위가 그대로인 항목** — AI 판단을 그대로 받아들인 수
- **AI 상위 10건과 겹침** — 구성 자체가 얼마나 유지됐는지

### 동작 방식

```
CSV 업로드
   ↓
guard.validate_backlog()      필수 컬럼 · id 중복 · 공수 숫자 검사
   ↓
guard.mask()                  전화번호 · 이메일 · 계좌번호를 가림
   ↓
ai.call_structured()          OpenAI 호출, JSON 스키마 강제, 실패 시 1회 재시도
   ↓  (실패하면)
priority.rule_based()         (KPI 가중치 ÷ 공수) 로 계산하는 대체 경로
   ↓
Top 10 + 근거 + 제외 목록
```

**재현성을 위해 `temperature=0`, `seed=42` 로 고정**했습니다. 동점일 때는 `id` 순으로 정렬해 대체 경로도 항상 같은 결과를 냅니다.

### 알려진 한계

- 규칙 기반 대체 경로는 단어 겹침으로 KPI를 고릅니다. "가입 신청서 임시 저장"처럼 설명에 `이탈` 이 들어가면 `신규 가입 전환` 대신 `해지율 감소` 로 붙을 수 있습니다. 화면에 "KPI 연결이 불확실해 점수를 낮춤"으로 표시됩니다.
- 공수(`effort_days`)는 사람이 입력한 값을 그대로 씁니다. 추정하지 않습니다.
- 우선순위 이력은 저장하지 않습니다 (2차 프로젝트 범위). 새로고침하면 보드 배치가 초기화됩니다.
- 보드 드래그는 HTML5 drag and drop 을 씁니다. 데스크톱 브라우저 기준이며 모바일 터치 드래그는 지원하지 않습니다.
- 보드의 "상대 평가" 를 켜면 영향도가 **이번 백로그 안에서의 상대 위치**를 뜻합니다. 다른 분기의 보드와 칸 위치를 직접 비교하면 안 됩니다.

### 문제가 생기면

| 증상 | 원인과 해결 |
| --- | --- |
| `OPENAI_API_KEY 가 설정되지 않았습니다` 경고 | 정상입니다. 규칙 기반으로 계산됩니다. 키를 쓰려면 `.env` 에 넣고 재실행 |
| `ModuleNotFoundError: streamlit` | 가상환경을 활성화했는지 확인 후 `pip install -r requirements.txt` |
| 화면이 빈 채로 멈춤 | 터미널에 뜬 오류 메시지를 확인하세요. 대부분 CSV 인코딩 문제입니다 (UTF-8 로 저장) |
| 지도에 점은 보이는데 배경 지도가 안 나옴 | 배경 지도 타일은 인터넷이 필요합니다. 오프라인이면 점만 보입니다 |
