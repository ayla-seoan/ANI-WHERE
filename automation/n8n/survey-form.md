# 사용자 테스트 기록 폼 (구글 폼)

`docs/user-test/plan.md` 의 과업 T1~T4 를 **진행자(나)가** 참가자 옆에서 재며 적는 폼. 참가자 한 명이 끝날 때마다 한 번 낸다.
마지막 세 문항(헷갈린 곳 · 만족도 · 다시 쓸 의향)은 참가자에게 물어보고 그대로 적는다.

> 개인정보: **이름 · 나이 · 연락처 문항을 만들지 않는다.** 참가자는 `P1, P2 …` 번호로만.
> 폼 설정에서 **'이메일 주소 수집' 을 끈다.** 자유 답변에 전화번호·이메일이 들어가도 n8n 이 `[전화번호]` `[이메일]` 로 지운다.

문항 이름은 **아래 글자 그대로** 쓴다 (n8n 이 이 이름으로 읽는다).

| 문항 이름 | 형식 | 선택지 · 설명 |
| --- | --- | --- |
| 참가자 번호 | 단답형 (필수) | `P1` 처럼. 이름을 적으면 n8n 이 그 응답을 버린다 |
| 회차 | 객관식 (필수) | `1차` (11/25, 물어보기 없이 목록·필터·지도만) · `2차` (11/30, 배포 주소 그대로) |
| T1 성공 | 객관식 | `Y` · `N` — 이번 주말 서울에서 열려 있는 팝업 하나를 찾아 상세 화면 열기 |
| T1 소요초 | 단답형 (숫자) | 스톱워치 초. 180초가 넘으면 자동으로 실패 처리 |
| T1 막힌 지점 | 단답형 | 멈칫한 곳 · 잘못 누른 버튼 (없으면 비움) |
| T2 성공 / T2 소요초 / T2 막힌 지점 | 위와 같음 | 주술회전 팝업을 찾아 북마크 |
| T3 성공 / T3 소요초 / T3 막힌 지점 | 위와 같음 | 북마크한 팝업이 내 캘린더에 있는지 확인 |
| T4 성공 / T4 소요초 / T4 막힌 지점 | 위와 같음 | 가기 전에 공식 공지(참고 웹사이트 첫 링크) 열기 |
| 가장 헷갈렸던 곳 | 장문형 | 참가자에게 묻는 한 줄 질문 |
| 만족도 | 직선 단계 1~5 | 1 = 불편했다 · 5 = 편했다 |
| 다시 쓸 의향 | 객관식 | `있다` · `모르겠다` · `없다` |

폼 응답은 **구글 시트로 연결**한다 (폼 → 응답 → 스프레드시트에 연결). 그 시트에 탭을 하나 더 만들어 이름을 **`정리`** 로 하고,
첫 줄에 `참가자 · 버전 · 과업 · 성공 · 소요초 · 막힌 지점 · 메모 · 받은시각` 을 적어 둔다 (`docs/user-test/results.csv` 와 같은 칸 + 받은시각).
