# 사용자 테스트 정리

docs/user-test/plan.md 의 과업(T1~T4)으로 진행한 테스트를 정리한다.

## 순서

1. 사용자가 준 메모에서 참가자마다 과업별로 `성공(Y/N)`, `소요초`, `막힌 지점` 을 뽑는다.
   - 참가자는 P1, P2… 번호로만. 이름·나이·연락처가 메모에 있어도 옮기지 않는다.
   - 메모에 없는 값은 비워 둔다. 추측해서 채우지 않는다 (특히 소요초).
   - 180초를 넘겼거나 도움을 받았으면 성공 = N.
2. docs/user-test/results.csv 맨 아래에 줄을 **추가**한다 (예전 줄은 고치지 않는다). 칸 순서:
   `참가자,버전,과업,성공,소요초,막힌 지점,메모`
3. `python -X utf8 scripts/user_test_report.py --save` 를 돌려 표를 만든다.
4. 막힌 지점을 묶어 **다음에 고칠 것 3개**를 제안한다. 각 항목에 (몇 명이 막혔나 · 어느 과업 · 고칠 방법 · 예상 효과) 를 적고,
   PRD.md 의 우선순위 기준(사용자 수 × 막힘 정도 ÷ 만드는 데 드는 날)으로 순서를 매긴다.
5. 고친 뒤에는 같은 과업으로 다시 테스트해 `버전` 칸을 `2차-수정` 처럼 바꿔 쌓으면 전후 비교가 된다.
