# Notion 트래커에서 가져오는 규칙

ANI:WHERE 가 Notion **'🎀 애니 팝업·콜라보 트래커'** DB 에서 팝업을 가져올 때 지키는 규칙입니다.
코드는 `common/notion_sync.py` 한 곳에 있습니다.

## 언제 가져오나

- `.env` 에 `NOTION_TOKEN` 이 있으면 메인 화면을 열 때 가져옵니다. 최대 1시간에 한 번이고, 마지막으로 확인한 시각은 `data/notion_sync.json` 에 남습니다.
- 키가 없으면 Notion 연결(Claude 의 Notion 도구)로 표를 읽어 와 같은 함수(`import_rows`, `sync_intros`)에 넣습니다.
- 먼저 임시 복사본에 넣어 보고(dry run) 결과를 확인한 뒤 실제 `data/cafes.json` 에 넣습니다.

## 어떤 행을 가져오나

| 조건 | 처리 |
| --- | --- |
| 검수상태가 **검토 완료** | 가져온다 |
| 검수상태가 **검토 필요** | 가져오지 않는다 |
| 기간(시작·종료)이 비어 있음 | 가져오지 않는다 |
| 작품명이나 장소명이 비어 있음 | 가져오지 않는다 |
| 이미 끝난 행사, 좌표를 못 찾은 곳 | 가져오지 않는다 (등록할 때와 같은 검사) |
| 예전에 가져왔다가 지도에서 내린 행사 | 다시 가져오지 않는다 |

## Notion 칸 → 앱 칸

| Notion 칸 | 앱 칸 | 규칙 |
| --- | --- | --- |
| 작품명 | 작품 | 끝의 괄호는 뺀다 (`프로젝트 세카이 (프로세카)` → `프로젝트 세카이`) |
| 장소명 | 카페명 | 여러 곳이 함께 적혀 있으면 첫 곳만 (`애니플러스 서울 합정점 / 부산 서면점` → 첫 지점) |
| 주소 | 주소 | 비어 있으면 장소명으로 위치를 찾는다 |
| 위도 · 경도 | 지도 위치 | 있으면 그대로, 없으면 주소로 찾는다 |
| 기간 | 시작일 · 종료일 | |
| 캐릭터 | 캐릭터 | `,` `·` 로 나눈다 |
| 특전 · 굿즈 | 특전 · 굿즈 | `/` `,` 로 나눈다 |
| 이벤트 · 특전 문구 | 이벤트 추가 정보 | 간편등록과 같은 낱말 표로 고른다 |
| 공식공지 · 출처 · 주최링크 · 참고링크 | 참고 웹사이트 | 이 순서로 모으고 겹치는 주소는 한 번만. `recal.kr` 은 맨 뒤 (다른 사이트가 없으면 첫 번째). 최대 5개 |
| 이미지 · 파일과 미디어 | 포스터 · 추가 이미지 | 내려받아 저장. 첫 장이 포스터 |
| 팝업소개 | 팝업 소개 | 아래 '팝업 소개' 규칙 |
| 소개출처 | 소개 출처 (`intro_src`) | 첫 주소만. 상세 화면 팝업 소개 옆 **출처 보기** 버튼. 소개가 없으면 출처도 두지 않는다 |
| 지점 | 지점마다 따로 | 아래 '여러 지점' 규칙 |

- '확인 필요', '미확인' 처럼 비어 있는 것과 같은 값은 빈칸으로 봅니다.
- 앱에 쌓는 기록의 방법은 **AI 자동 수집**, 수정한 사람은 **AI** 입니다 (수정 이력에 그대로 보임).
- 기록의 메모(`note`) 끝에 `| notion:<페이지 번호>` 를 붙입니다. 앱에서 고쳐 저장해도 이 표시는 남깁니다 (다음 가져오기 때 같은 팝업으로 알아보는 열쇠).

## 팝업 소개

- Notion 서식을 평문으로 정리합니다.
  - `<br />` 는 줄바꿈으로, `\[` `\~` 같은 이스케이프는 원래 글자로.
  - `[글자](주소)` 링크는 글자만 남깁니다.
  - 줄 맨 앞의 `[배경]` 같은 소제목은 상세 화면에서 민트색 굵은 글씨로 보입니다.
- **전화번호·이메일은 저장하지 않습니다.** 휴대폰·일반 전화(02-, 0507- 등)·이메일이 든 줄(보통 '문의')은 통째로 뺍니다.
- 최대 3,000자.
- **Notion 이 기준입니다.**
  - Notion 에서 소개가 바뀌면 앱도 바꿉니다.
  - Notion 에서 소개를 지우면 앱에서도 비웁니다.
  - 다만 **사람이 앱에서 직접 쓰거나 고친 소개는 덮어쓰지 않습니다** (지금 소개를 마지막으로 바꾼 기록의 수정한 사람이 AI 가 아니면 그대로 둠).
- 이미 있는 팝업도 이 규칙으로 소개·출처만 맞추고, 다른 칸은 건드리지 않습니다.

## 같은 팝업인지 알아보는 순서

이미 앱에 있으면 새로 만들지 않습니다 (빈 이미지와 팝업 소개만 맞춤). 위에서부터 하나라도 맞으면 같은 팝업입니다.

1. 같은 Notion 페이지 (예전 기록까지 포함해 `notion:<번호>` 표시가 있음)
2. 같은 작품 + 같은 카페명 (띄어쓰기만 다른 것도 같게 봄)
3. 작품명이 한쪽이 다른 쪽을 품고 + 기간이 겹치고 + 위치가 500m 안이거나 도로명 주소가 같음
4. 같은 작품 + 시작일·종료일이 똑같고 + 같은 시·구 (매장 이름·주소 표기가 달라도. 예: 'SMG CAFE 신촌점' 과 '현대백화점 신촌점 유플렉스')

알려진 한계: 같은 건물에서 기간이 겹치는 같은 작품의 **다른** 행사는 3번에 걸려 하나로 묶일 수 있습니다
(예: 주술회전 BOX cafe&space 홍대점 09.23~12.01 과 주술회전 5주년 문화제 페어 애니메이트 카페 홍대점 10.24~11.15).
이런 경우는 가져오기 결과를 보고 따로 넣습니다.

## 여러 지점

- '지점' 칸에 한 줄에 하나씩 `지점명|위도|경도|주소` 로 여러 곳이 적혀 있으면 지점마다 따로 가져옵니다.
- 첫 지점은 원래 페이지 번호를, 둘째부터는 `페이지번호-2` 처럼 번호를 붙여 서로 겹치지 않게 합니다.
- 좌표가 `(좌표없음)` 이면 주소로 위치를 찾습니다.
- 다른 Notion 행으로 이미 들어온 지점은 위 '같은 팝업' 규칙으로 걸러집니다.

## 저장 방식

- 저장소는 append-only 입니다. 고치거나 채울 때도 기존 행을 덮어쓰지 않고 새 행을 쌓습니다.
- 그래서 가져온 내용이 틀렸으면 상세 → 수정하기 → 수정 이력에서 **이 버전으로 돌아가기** 로 되돌릴 수 있습니다.
