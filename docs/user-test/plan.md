# 사용자 테스트 계획 (PO)

PRD 의 사용자 지표(과업 성공률 80% 이상, T1 평균 60초 이하)를 재는 방법.

## 누구와
- 애니 팝업에 가 본 적 있는 사람 **3~5명** (리뷰 그룹·지인). 앱을 처음 보는 사람이면 더 좋다.
- 기록에는 이름 대신 **P1, P2…** 만 적는다. 나이·연락처는 받지 않는다.

## 언제 · 무엇으로
| 회차 | 날짜 | 버전 칸 | 앱 |
| --- | --- | --- | --- |
| 이전 | 1일차 (11/25) | `1차` | 2차 기능(`물어보기`) 없이 — 목록·필터·지도만 쓰라고 안내 |
| 이후 | 4일차 (11/30) | `2차` | 배포 주소 그대로 |

같은 사람이 두 번 하면 익숙해져서 빨라지므로, **이전·이후는 다른 사람**으로 하거나 과업 속 작품·지역을 바꾼다 (아래 '바꿔 쓰기').

## 진행 (1인 10분)
1. "생각나는 걸 소리 내어 말해 주세요. 앱을 시험하는 거지 당신을 시험하는 게 아니에요." 라고 말한다.
2. 과업 카드를 하나씩 주고 휴대폰 스톱워치로 잰다. **도와주지 않는다.** 3분이 넘으면 멈추고 실패로 적는다.
3. 막힌 곳(멈칫한 곳, 잘못 누른 버튼)을 그대로 적는다.
4. 끝나고 한 줄 질문: "가장 헷갈렸던 곳 하나는?"

## 과업
| 번호 | 과업 카드에 적을 문장 | 성공 기준 | 바꿔 쓰기 |
| --- | --- | --- | --- |
| T1 | 이번 주말 **서울**에서 열려 있는 팝업 하나를 찾아 상세 화면을 열어 주세요 | 기간이 주말에 걸친 서울 팝업 상세가 열림 | 부산 / 다음 주 |
| T2 | **주술회전** 팝업이 있는지 찾고, 있으면 북마크해 주세요 | 해당 팝업 북마크 아이콘이 채워짐 | 원피스 / 블루 아카이브 |
| T3 | 방금 북마크한 팝업이 **내 캘린더**에 들어갔는지 확인해 주세요 | 캘린더에서 막대를 찾아 가리킴 | — |
| T4 | 그 팝업에 가기 전에 **공식 공지**를 열어 주세요 | 참고 웹사이트의 첫 링크를 새 탭으로 엶 | — |

## 기록
`docs/user-test/results.csv` 에 과업마다 한 줄:

```
참가자,버전,과업,성공,소요초,막힌 지점,메모
P1,1차,T1,Y,74,날짜 필터를 못 찾음,
```

정리는 `python -X utf8 scripts/user_test_report.py --save` 또는 Claude Code 에서 `/user-test-report`.
