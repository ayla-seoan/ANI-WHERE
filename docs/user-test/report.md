숫자 규칙은 `common/stats.py` (`survey_verify` · `survey_compare`) — 관리자 '사용자 테스트' 탭 · n8n 메일과 같다.

## 참가자 · 방법

| 항목 | 내용 |
| --- | --- |
| 검증된 참가자 | **1차 0명 · 2차 0명** (같은 사람 0명) |
| 검증 규칙 | 구글 폼 응답 탭에 있고 받은 시각이 지금보다 앞선 응답만. '정리' 탭 49명 중 제외 49명 (폼에 없음 15 · 미래 시각 34 · 시각 없음 0) |
| 응답 기간 | - |
| 모집 | 리뷰 그룹 · 지인 중 애니 팝업에 가 본 사람 (이름 · 나이 · 연락처 · 이메일은 받지 않음) |
| 방법 | 참여자가 혼자 배포 주소에서 질문 1~4 를 해 보고 구글 폼에 직접 답함 (`automation/n8n/survey-form.md`). 1차 폼 = 로그인 · 물어보기가 없던 첫 버전, 2차 폼 = 지금 버전 |
| A/B | A = 평소 방법(SNS · 검색)으로 '이번 주말 서울 팝업 찾기'에 보통 걸리는 시간, B = ANI:WHERE 로 같은 일(질문 1) |
| 시간 측정의 한계 | 스톱워치가 아니라 **구간을 고르는 자기 보고** — 구간 가운데 값(초)으로 바꾼 **대략값**이다 |
| 원자료 | [`raw/survey_verified.csv`](raw/survey_verified.csv) — 닉네임은 P번호, 자유 답변의 전화번호 · 이메일은 가림 |

## 결과

아직 검증된 응답이 없다. 설문 폼으로 3~5명 이상 받은 뒤 다시 돌린다.
