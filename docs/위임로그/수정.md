# 수정 — 무엇을 고쳤나, 무엇을 직접 했나, 그 이유

> 위임 로그 6칸 중 **수정**. 번호는 `목표.md` 와 같습니다.
> **AI 가 낸 것을 고친 것** 과 **AI 에게 맡기지 않고 내가 직접 한 것(결정 포함)** 을 나눠 적습니다. AI 가 틀린 사례 전체는 `docs/ai-mistakes.md`.

| 번호 | 맡긴 일 | AI 결과에서 고친 것 | 내가 직접 한 것 · 결정한 것 | 이유 |
| --- | --- | --- | --- | --- |
| W01 | 지표 대시보드 | — | 북극성 지표 정의(방문 전 확인할 5가지 정보), 기준 시점 10/30 | 무엇을 '완결' 로 볼지는 서비스 목표라 PO 가 정해야 함 |
| W02 | 팝업 물어보기 | '홍대 근처' 를 내 위치로 오해하던 것, 웹 대화창이 민감정보를 가리지 않고 찾아 0건이던 것 | 추천 기준(별점 → 리뷰 수, 진행 중만), 건수는 AI 가 아니라 규칙으로 세기, 평가 세트를 보고 고친 점수라 새 질문으로 다시 재기 | AI 가 숫자를 세면 틀릴 수 있고, 같은 문제로 채점하면 점수가 부풀려짐 |
| W03 | Supabase 이관 · RLS | — | 프로젝트 만들기, 서울 리전, 'Automatically expose' 끄기, anon 키만 쓰기, 키를 넘기는 것 | 계정 · 키 · 과금은 사람이 책임질 일 |
| W04 | 자동 테스트 · 훅 | 테스트 결과를 보지 않고 커밋하던 것 → 결과를 본 뒤에만 | 테스트가 실제 데이터를 건드리지 않게 하라는 조건 | 테스트가 운영 데이터를 바꾸면 테스트 자체가 사고가 됨 |
| W05 | 회원가입 · 개인정보 | 로그아웃 쿠키가 브라우저에 닿지 않던 것 | 만 14세 미만은 가입 차단(법정대리인 절차는 범위 밖, 한계로 명시), 비밀번호 찾기 포기, 연락처 · 리전 확정 | 연락처를 안 받는 대신 생기는 불편을 받아들이는 맞바꿈은 사람이 판단 |
| W06 | 공개 웹 = 앱과 같게 | '로그인 · 물어보기가 없다', 'Streamlit 으로 넘어간다' 를 화면에서 보고 4번에 걸쳐 다시 맡김 | '공개 웹은 읽기 전용' 규칙을 바꾸기로 결정(CLAUDE.md · PRD 갱신), 비밀 키는 Vercel 에 직접 입력, 사진 저장소 SQL(011) 직접 적용 | 범위를 바꾸는 결정과 비밀값 입력은 AI 에게 넘기지 않음 |
| W07 | 속도 개선 | — | 데이터 갱신 시점(08:45 · 저장 때 · 30분 안전 갱신), 관리자 '새로 불러오기' | 빠르게 하려면 '얼마나 오래된 데이터까지 괜찮은지' 를 정해야 함 |
| W08 | 간편 로그인 배포 오류 | 같은 code 를 두 번 교환하던 것, 업데이트 줄 위치를 반대로 옮긴 것 | 잘린 키 교체 · Secrets 반영, 배포 시점 | 로컬에서는 재현되지 않아 내가 배포 화면을 눌러 알려 줘야 했음 |
| W09 | 내린 팝업 주간 정리 | — | 지울 범위(팝업 + 리뷰 + 북마크 + 사진, 삭제 요청으로 내린 것 포함), append-only 의 두 번째 예외로 인정 | 되돌릴 수 없는 삭제라 영향 숫자를 보고 사람이 범위를 고름 |
| W10 | 사진 사고 확인 | 로컬 시험 서버가 실제 `.env` 로 운영 DB 에 붙어 사진을 깨뜨린 것 → 끄고 11곳 되돌림 | 다른 무료 프로젝트를 멈추고 운영 프로젝트를 직접 다시 켬. '시험 서버는 임시 데이터로만' 규칙 추가 | AI 계정에는 운영 Supabase 권한이 없고, 같은 사고를 규칙으로 막아야 함 |
| W11 | 랭킹 맞추기 | 11/19 에 '기준을 맞췄다' 고 했는데도 순위가 달랐음 → 규칙을 한곳으로 모으고 공통 시험 추가 | 랭킹 기준(최근 7일 북마크 · 리뷰, 조회 수는 세지 않음) | 두 곳에 따로 짠 규칙은 말로 맞춰도 어긋남 |
| W12 | 공유 전 점검 | README 가 간편등록을 'OpenAI' 로 설명(실제는 규칙), 관리자 탭이 시트의 모든 줄을 실측처럼 셈 → 검증된 응답만 세게 | 설문은 실제 3~5명에게 다시 받기, 연락처 메일 따로 만들기 | 평가 근거는 실제 응답이어야 하고, 문서는 코드와 대조해야 함 |
| W13 | Notion 배치 · 배지 | 배치 직후 화면 확인 없이 '반영됨' 이라 보고한 것 → 운영 DB · 사이트를 직접 열어 확인하는 순서로 | 배포(PR 병합)는 "다 되면 배포해줘" 라고 한 뒤에만 진행. "vercel 에서는 안 보인다 · 여전히 똑같다" 를 내 화면에서 보고 알려 줌 | 운영 반영은 사람이 승인, 내 기기 화면은 나만 볼 수 있음 |
