## 검증하지 못한 것 (그대로 적음)

- W03: 코드를 받은 날에는 실제 DB 연결을 확인하지 못했고, 프로젝트를 만든 뒤에 직접 돌려 확인했습니다.
- W13: 배치 직후에는 사이트 화면을 열어 보지 않고 "반영했다" 고 보고했습니다. 공개 웹은 데이터를 10분 동안 기억해서 그동안 새 팝업이 보이지 않았습니다 (`docs/ai-mistakes.md` 11/24).
- W13: 서버가 빨강 배지를 내려 주는 것은 확인했지만, 사용자 브라우저에서 예전 화면이 보인 이유(브라우저 · 설치 앱 캐시로 추정)는 확인하지 못했습니다.
- W15: "아직 vercel 배포 안된거 같은데" 에는 운영 사이트를 다시 열어 새 CSS 가 이미 나가는 것을 확인하고 보고했습니다 (반영까지 1~2분 · 브라우저 캐시).
- W16: 회원 · 관리자 장면은 운영 DB 에 시험 가입을 하지 않으려고 로컬 시험 서버에서 찍어서, 그 부분의 후기 · 요청은 시연용 데이터입니다.
