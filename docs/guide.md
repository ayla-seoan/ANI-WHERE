# ANI:WHERE 사용법 안내

애니 팝업·콜라보 카페·굿즈 행사를 지도와 리스트로 찾고, 북마크해서 내 캘린더로 챙기는 서비스예요.
궁금한 기능을 눌러 바로 가 보세요.

## 지도로 보기

- 메뉴바의 **지도로 보기**를 누르면 열려요.
- **왼쪽 데일리 팝업 노트**: 날짜(‹ ›)와 지역(‹ ›)을 바꿔 가며 그날 열려 있는 팝업을 볼 수 있어요. `오늘` 표시가 있는 날이 오늘이에요.
- **가운데 지도**: 민트색 핀이 팝업 자리예요. 핀에 마우스를 올리면 카드가 뜨고, 누르면 그 자리의 팝업 목록이 열려요. 목록에서 팝업을 누르면 상세 화면으로 가요.
- 오른쪽 위 `+` `-` 로 확대·축소, 위치 권한을 허용하면 내 위치 기준으로 볼 수 있어요.
- **오른쪽 물어보기 창**에서 "이번 주말 홍대 팝업"처럼 물어볼 수 있어요.

<a id="list"></a>

## 리스트로 보기

- 메뉴바의 **리스트로 보기**: 팝업을 포스터 카드로 모아 봐요.
- 카드 오른쪽 위 배지: `진행 중`(민트) · `D-n` 오픈 예정(파랑) · `마감임박` 3일 안에 끝남(빨강).
- 위쪽 줄에서 **북마크**만 보기, **지역 고르기**(여러 곳 가능), **정렬**(최신순·오픈 임박순·종료 임박순·인기순 등)을 고를 수 있어요.
- 메뉴바의 돋보기를 누르면 작품·캐릭터·기간으로 검색해요. 결과가 없으면 어떤 조건을 빼면 몇 곳이 나오는지 버튼으로 알려 드려요.
- 처음엔 24곳만 보이고, 아래 **N건 더보기**를 누르면 더 불러와요.
- 카드를 누르면 상세 화면(위치·일정·특전·참고 웹사이트·리뷰·블로그 후기)이 열려요.

<a id="cal"></a>

## 내 캘린더 · 알림

- 회원만 쓸 수 있어요. 메뉴바의 **내 캘린더**를 누르세요.
- **왼쪽 캘린더**: 북마크한 팝업을 날짜 막대로 보여 줘요.
- **가운데**: 북마크 · 다녀온 팝업(내가 쓴 다녀온 후기) · 최근 본 팝업(최대 10개). 예정인 팝업은 파란색이에요.
- **오른쪽 알림 받은 내역**: 최근 3일 알림과 내 주변 추천(20km 안, 별점 → 후기 많은 순, 최대 3곳).
- **종 알림**: 북마크한 팝업의 오픈 3일 전~당일, 종료 3일 전~당일에 알려 드려요. 관리자 공지와 삭제 요청 결과도 여기로 와요.

<a id="bookmark"></a>

## 북마크

- 카드 오른쪽 아래나 상세 화면의 북마크 버튼을 누르면 저장돼요. 다시 누르면 해제돼요.
- 북마크는 **회원마다 따로** 저장돼요. 로그인하지 않았을 때 누르면 로그인 화면으로 가요.

<a id="add"></a>

## 팝업 등록하기

1. 로그인한 뒤 화면 **오른쪽 아래 코랄색 `+` 버튼**을 눌러요.
2. 작품 이름 · 카페(장소) 이름 · 기간 · 주소를 넣어요. 포스터 사진, 특전·굿즈, 참고 웹사이트는 선택이에요.
3. **저장**하면 바로 지도와 리스트에 올라가요.

- 매일 아침 자동 수집도 돌아서, 이미 올라와 있는 팝업일 수 있어요. 먼저 검색해 보세요.
- 전화번호·이메일 같은 개인정보는 저장되지 않아요.

<a id="edit"></a>

## 정보 수정하기

1. 고칠 팝업의 상세 화면을 열어요.
2. 오른쪽의 **수정하기** 탭에서 날짜·주소·소개·사진 등을 고치고 저장해요 (회원만).

- 고친 기록은 모두 남아서, 잘못 고쳐도 예전 내용으로 되돌릴 수 있어요.
- 리뷰는 내가 쓴 리뷰만 고칠 수 있어요.

<a id="delete"></a>

## 삭제 요청하기

- 글은 바로 지워지지 않고 **삭제 요청**으로 받아요.
- 상세 화면에서 **삭제 요청**을 누르고 사유를 적어 보내면, 관리자가 확인해서 승인하거나 거부해요.
- 결과는 **종 알림**으로 알려 드려요.

<a id="login"></a>

## 로그인 · 회원가입

- 메뉴바 오른쪽 **로그인** → 카카오·네이버 **간편 로그인** 또는 **아이디로 가입**.
- 가입할 때는 닉네임(선택)과 필수 동의 3개(만 14세 이상 · 이용약관 · 개인정보 수집·이용)만 받아요. 이메일·전화번호는 받지 않아요.
- **로그아웃 · 닉네임 바꾸기 · 프로필 사진 · 탈퇴**는 메뉴바의 내 닉네임을 누르면 나오는 마이페이지에 있어요.
- 탈퇴하면 닉네임·사진·접속 기록을 지난 기록까지 바로 지워요. 자세한 내용은 [개인정보처리방침](./privacy)을 봐 주세요.

## 물어보기 (ANI:WHERE에게 물어보기)

- PC는 지도·리스트 오른쪽 창, 휴대폰은 오른쪽 아래 말풍선 버튼이에요.
- **작품 · 지역 · 날짜**를 넣어 물어보면 모두 맞는 팝업만 찾아 드려요. 예: "치이카와 이번 달 서울 팝업 있어?", "이번 주말 홍대 팝업".
- 이런 것도 물어볼 수 있어요: "내 주변 가까운 팝업", "곧 끝나는 팝업", "팝업 추천해줘", "리뷰 가장 많은 팝업 3개", "내 닉네임 뭐야?", "지금 내 위치 어디야?", "내 북마크 보여줘", "팝업 몇 개 있어?", "등록 어떻게 해?".
