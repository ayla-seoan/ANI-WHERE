# ANI:WHERE 디자인 핸드오프 (A안 확정)

Claude Design 캔버스 「ANI:WHERE 로고·페이지 시안 3방향」에서 확정한 A안을 코드로 옮기기 위한 묶음입니다.
원본 캔버스: https://claude.ai/artifact/Jf5jKYdTmNj3eXCapg67dD (본인 계정에서만 열림)

## 1. 이 묶음 읽는 법

- `screens/*.dc.html` 은 **디자인 시안 파일**입니다. 그대로 앱에 넣는 코드가 아닙니다.
  - `{{ 값 }}`, `<sc-for>`, `<sc-if>`, `<x-dc>` 는 Claude Design 캔버스 전용 문법입니다. 반복되는 카드는 맨 아래 `<script>` 의 `renderVals()` 안 배열에 예시 데이터가 들어 있습니다.
  - 색 · 간격 · 모서리 · 글꼴 크기는 각 요소의 `style="…"` 에 그대로 적혀 있으니 값을 읽어 옮기면 됩니다.
  - 브라우저로 직접 열면 캔버스 런타임이 없어 반복 영역이 비어 보일 수 있습니다. 모양은 원본 캔버스 링크에서 확인하세요.
- 시안 속 팝업 이름 · 날짜 · 별점 · 닉네임 · 주소 · 후기 내용은 모두 **예시 데이터**입니다. 실제 데이터(`popups_current`, 리뷰 표)로 바꿔 연결합니다.
- `tokens.json` = 기존 ANI:WHERE 디자인 시스템 토큰(앱 `app_cafemap.py` CSS 에서 옮긴 값).
- `assets/` = 확정 로고(배경 투명 PNG)와 토끼 마스코트(로고에서 잘라낸 것, 아래쪽 일부 깎임 — 원본 파일이 있으면 교체 권장).

| `A-Home` / `A-Mobile` | 홈 PC / 모바일 | `_home_*`, `HOME_CSS` | 홈 페이지 |

## 3. 바뀐 점 요약

1. **로고**: `assets/aniwhere_logo.png` 로 교체. 높이 32px 미만이면 마스코트만. 물어보기 도우미 얼굴 · 앱 아이콘 · 파비콘 = `aniwhere_mascot.png`.
2. **홈**: 섹션마다 레이아웃을 다르게 — 북마크(동그라미 줄) · 랭킹(배너+목록) · 신규(가로 넘기기 + 더보기 카드) · 곧 끝나는(7일 칸) · **사전예약(예약 오픈 날짜 타임라인, 보라 #6c5ce7)** · **후기 모음(높이 제각각 3단, 종류 칩)**.
3. **팝업 상세**: 위 = 사진 + 정보 2단, 아래 = 화면 폭 전체 탭(리뷰 · 블로그 후기 · 수정하기).
   - 리뷰 탭: 왼쪽 리뷰 쓰기(종류 · 별점 · 사진 4장 · 사진 주의 문구), 오른쪽 평균 · 점수 분포 · 사진 모아 보기 · 리뷰 카드(사진 120px 최대 4장 + N).
   - 수정하기 탭: 등록 7단계와 같은 순서로 **모든 칸 수정**, 바뀐 칸 민트 표시, 하단 고정 저장 바, 오른쪽 '저장하면 이렇게 바뀌어요'(이전→이후) + 수정 이력(되돌리기).
4. **리스트 PC**: 검색 아이콘에서 펼쳐지는 필터 말풍선, 북마크 · 지역 · 정렬 줄, 카드 마우스 올림 시 캐릭터 · 주소 · 특전.
5. **내 캘린더 PC**: 달력 400px로 작게, 북마크 · 다녀온 · 최근 본 목록을 넓게.
6. **마이페이지(신규)**: 프로필 + 랭크 도장, 숫자 3개, 내 후기 도장 카드, 내가 쓴 후기, 설정(닉네임 · 알림 · 프로필 사진 선택 동의 · 처리방침 · 로그아웃 · 탈퇴).
