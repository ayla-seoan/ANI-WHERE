# Chip

여러 개 중 하나를 고르거나, 눌러서 바로 물어보는 작은 알약.

- 홈 칸의 지역 고르기(`전체 · 마포 · 부산 · 송파`), 후기 모음의 종류(`전체 · 다녀온 후기 · 기대평 · 기타`), 물어보기의 추천 질문.
- 고른 칩: `accent` 테두리 + `accent-soft` 바탕 + `accent-ink` 굵은 글자.
- 걸린 필터 칩(리스트 목록 위, 40px): 지금 걸려 있는 조건을 하나씩 보여 주고, 끝의 `close` 를 누르면 그 조건만 풀린다.
- 한 줄에 다 안 들어가면 다음 줄로 넘긴다 (가로 스크롤 없음).

손으로 옮김: `app_cafemap.py` 의 홈 `st.pills`, `.apn-chips` · 웹 `a-home.css` 의 `.ah-chip`, `a-browse.css` 의 `.fchip`.
