# PillTabs

화면이나 목록을 바꾸는 알약 탭. 고른 탭 하나만 흰 알약이 된다.

- **메뉴바**: 바탕 `gnb`(연민트), 아래 두 모서리 `radius-gnb`(28px), 높이 76px, 로고 52px(모바일 44px). 탭 글자 15px · 600, 고른 탭은 흰 알약 + 800 (밑줄은 쓰지 않는다). 모바일은 탭이 한 줄을 나눠 쓴다(14px).
- 메뉴바 오른쪽의 검색 · 알림 · 프로필은 44px 동그라미. 평소에는 바탕이 **투명**하고, 커서를 올렸을 때만 흰 바탕(위 그림의 종 모양)이 된다. 프로필 동그라미는 `mint-line` 2px 테두리. 로그인 전에는 그 자리에 글자 버튼 `로그인`.
- **목록 탭**(내 캘린더의 `북마크 · 다녀온 팝업 · 최근 본`): `gray-soft` 알약 판 안에 같은 폭으로 나눈 탭, 고른 탭은 흰 알약 + 800, 나머지는 `ink-soft`.
- 상세 아래쪽의 `리뷰 · 블로그 후기 · 수정하기` 는 알약이 아니라 **밑줄 탭**(고른 탭 아래 `accent` 줄)이다 — 화면 폭 전체를 쓰는 큰 묶음이라서.

손으로 옮김: `app_cafemap.py` 의 `_gnb`, `.st-key-gnb_tabs`, `.st-key-box_tabs` · 웹 `a-shell.css` 의 `.gnb-tabs`, `a-member.css` 의 `.am-tabs`.
