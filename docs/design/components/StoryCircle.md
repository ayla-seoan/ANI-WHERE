# StoryCircle

홈 맨 위 동그라미 줄. 회원은 '북마크 팝업'(내가 북마크한 팝업 하나에 하나), 손님은 '특전 있는 작품들'. 누르면 그 팝업 상세.
A안에서도 이 줄은 **개편 전 모양 그대로** 둔다 (11/25 결정).

- 72px 동그라미, 민트→노랑 고리(`accent` → `#7fe0cf` → `#ffd66b`), 흰 3px 테두리 안에 포스터.
- 동그라미 아래쪽에 걸친 지역 이름 알약(`mint` 바탕 · 흰 글자 · 흰 테두리 1.5px), 그 아래 작품 이름 한 줄(넘치면 …).
- 회원 줄의 맨 앞은 늘 `최애 추가하기`(점선 동그라미 + `add`) — 팝업을 골라 한 번에 북마크하는 창을 연다.
- 줄이 길면 마우스로 끌거나 양옆 ‹ › 로 넘긴다.

손으로 옮김: `app_cafemap.py` 의 `render_stories`, `STORY_CSS`.
