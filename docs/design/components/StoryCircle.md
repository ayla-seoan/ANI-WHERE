# StoryCircle

홈 '북마크 팝업' 줄의 동그라미. 내가 북마크한 팝업 하나에 하나, 누르면 그 팝업 상세.

- 72px 동그라미, 코랄→노랑 고리, 흰 3px 테두리 안에 포스터.
- 위에 지역 이름(`accent-deep` 알약), 아래 작품 이름 한 줄(넘치면 …).
- 맨 앞은 늘 `최애 추가하기`(점선 동그라미 + `add`) — 팝업을 골라 한 번에 북마크하는 창을 연다.
- 줄이 길면 마우스로 끌거나 양옆 ‹ › 로 넘긴다.

손으로 옮김: `app_cafemap.py` 의 `render_stories`, `STORY_CSS`.
