# PreTimeline

홈 '사전예약 팝업' 칸의 타임라인 항목. 예약해야 들어갈 수 있는 팝업을 **팝업이 열리는 날** 순서로 한 줄에 놓는다.

- 보라는 사전예약 전용이다: 가로줄 `purple-line` 3px, 날짜 알약(`purple-deep` 글자 · `purple-line` 테두리 1.5px), 점 14px(첫 항목만 `purple` 로 진하게).
- 카드: `line` 테두리 1.5px · 모서리 `radius-card`(16px), 포스터 4:3, 왼쪽 위 `사전예약 D-n` Badge, 작품 이름(Jua 17px `mint-ink`), 장소 · 기간(12.5px `ink-soft`). 커서를 올리면 테두리가 `purple`.
- 카드 아래 `북마크하고 오픈 알림 받기`(40px 보라 테두리 버튼) — 누르면 북마크되고, 팝업이 열리기 3일 전부터 알림이 온다. 북마크한 뒤에는 `purple` 로 채운다.
- 왼쪽 요약 칸(`purple-soft` 바탕): 칸 이름 · 한 줄 설명 · `N곳 예약 대기` · `사전예약 팝업만 보기`.
- 날짜는 팝업 오픈일이다. 예약이 열리는 시각 · 예약처는 데이터에 없어 보여 주지 않는다.

손으로 옮김: `app_cafemap.py` 의 홈 사전예약 칸(`ah_pre`) · 웹 `a-home.css` 의 `.ah-pre*`.
