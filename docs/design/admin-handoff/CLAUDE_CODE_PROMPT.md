# Claude Code 에 붙여넣을 요청문 (관리자 페이지)

> 이 폴더를 저장소의 `docs/design/admin-handoff/` 에 넣은 뒤 아래를 붙여넣으세요. 단계별로 나눠 요청하는 것을 권장합니다.

---

`docs/design/admin-handoff/README.md` 를 먼저 읽어 줘. Claude Design 에서 확정한 관리자 페이지 시안 8장이야.

규칙
- `screens/AdmX-*.dc.html` 은 디자인 시안이라 그대로 복사하지 말고, 색 · 간격 · 글꼴 · 레이아웃 값을 읽어서 지금 관리자 코드(Streamlit `common/admin.py` 쪽과 공개 웹 `web/` 관리자 화면)에 맞게 옮겨 줘.
- Streamlit 과 공개 웹 관리자를 같이 바꿔. 관리자만 볼 수 있는 권한 체크(`ADMIN_MEMBER_KEYS`)는 그대로 유지해.
- 시안 속 숫자 · 닉네임은 예시야 (README 4절). 실제 데이터에 연결하고, 데이터가 없으면 빈 상태를 보여 줘.
- README 6절의 새 기능(랭크 칸, 랭크 승급 알림, 강제 탈퇴)은 화면 자리만 만들고 DB · 동작은 건드리지 마.
- 끝나면 `python scripts/qa_report.py` 와 공개 웹 테스트를 돌려 결과를 알려 줘.

이번에 할 일 (1단계)
1. 관리자 화면의 위 탭을 시안처럼 **왼쪽 사이드바**로 바꿔 줘 (삭제 요청 대기 수 배지 포함).
2. 새 첫 화면 **'한눈에 보기'**(`AdmX-1Home`)를 만들어 줘 — 처리할 일 목록에서 삭제 요청 승인/거부가 바로 되게.

작업 전에 바꿀 파일 목록과 계획을 먼저 보여 주고, 내가 확인하면 시작해.
