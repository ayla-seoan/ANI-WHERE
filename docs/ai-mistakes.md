## 기록할 가치가 있는 것

- 입력에 없는 값을 만들어 낸 경우 (환각)
- 스키마는 통과했지만 내용이 틀린 경우
- 같은 입력인데 결과가 달라진 경우
- 프롬프트 한 줄을 고쳤더니 정확도가 눈에 띄게 바뀐 경우
