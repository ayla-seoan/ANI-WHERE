# AI 실수와 수정 기록

발견할 때마다 한 줄씩 추가합니다. 나중에 몰아서 쓰면 기억이 안 납니다.

| 날짜 | 입력 | AI가 낸 결과 | 문제 | 수정 방법 | 결과 |
| --- | --- | --- | --- | --- | --- |
| (예시) 11/3 | `11.1-7` | start 2026-11-01, end 2026-11-30 | 종료일 오독 | 프롬프트에 표기 예시 3개 추가 (cafe.v1 → v2) | 같은 유형 5건 모두 정상 |

## 기록할 가치가 있는 것

- 입력에 없는 값을 만들어 낸 경우 (환각)
- 스키마는 통과했지만 내용이 틀린 경우
- 같은 입력인데 결과가 달라진 경우
- 프롬프트 한 줄을 고쳤더니 정확도가 눈에 띄게 바뀐 경우

## 코딩 도우미(AI)가 화면 작업 중 틀린 것

AI 추출 결과가 아니라, 화면을 고치던 코딩 도우미가 잘못 만든 것과 고친 방법입니다. 같은 실수를 반복하지 않으려고 남깁니다.

| 날짜 | 요청 | 잘못된 결과 | 원인 | 수정 방법 |

| 10/29 | 지도 템플릿 색 변수 추가 | 사이트 전체 글꼴(Pretendard·Jua)이 사라짐 | `:root` 변수를 `@import` 앞에 넣어 글꼴 불러오기가 무시됨 | `@import` 를 `<style>` 맨 앞으로 |
