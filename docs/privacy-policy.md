# 개인정보처리방침

ANI:WHERE(이하 '서비스')는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다. 개인정보보호위원회 표준 개인정보처리방침의 항목 순서를 따랐습니다.

> 이 서비스는 부트캠프 2차 프로젝트로 만든 개인 서비스입니다. 필요한 최소한의 정보만 받고, 이메일·전화번호·실명·생일은 받지 않습니다.

## 1. 개인정보의 처리 목적

| 목적 | 내용 |
| --- | --- |
| 회원 식별·로그인 | 같은 사람인지 알아보고 로그인 상태를 유지 |
| 리뷰·수정 작성자 표시 | 리뷰·수정 이력에 닉네임(과 선택한 경우 프로필 사진)을 표시 |
| 북마크·내 캘린더·알림 | 북마크한 팝업의 오픈·종료 알림, 삭제 요청 처리 결과 알림 |
| 서비스 운영 통계 | 일별 접속 회원 수 (관리자 대시보드) |

## 2. 처리하는 개인정보 항목

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 필수 (카카오·네이버 가입) | 로그인 수단, 카카오·네이버 계정 번호를 **되돌릴 수 없게 바꾼 값**(해시), 닉네임, 약관 동의 시각 | 가입 화면 |
| 필수 (아이디 가입) | 아이디, **일방향 암호화한** 비밀번호, 닉네임, 약관 동의 시각 | 가입 화면 |
| 선택 | 프로필 사진 (카카오·네이버 프로필 사진 주소, 또는 직접 올린 사진) | 가입 화면 선택 동의, 마이페이지 |
| 자동 생성 | 접속한 날짜(회원 번호와 함께), 로그인 유지 쿠키, 알림 읽음 쿠키 | 서비스 이용 중 |
| 자동 생성 (손님) | 접속 IP 를 **되돌릴 수 없게 바꾼 값** (손님 북마크 구분용, IP 원문은 저장하지 않음) | 서비스 이용 중 |

받지 않는 정보: 이메일, 전화번호, 실명, 생일, 성별, 카카오·네이버 계정 번호 원래 값.
리뷰·공지·삭제 사유에 전화번호·이메일·계좌번호·주민번호·카드번호가 들어 있으면 저장하지 않습니다.

## 3. 보유 기간과 파기

| 항목 | 보유 기간 | 파기 방법 |
| --- | --- | --- |
| 회원 정보 (닉네임·사진·아이디·비밀번호) | **탈퇴할 때까지** | 탈퇴 즉시 지난 기록까지 지움 (닉네임·사진은 빈 값으로, 아이디·비밀번호 해시는 삭제) |
| 접속한 날짜 | 1년 (탈퇴하면 즉시) | 기간이 지나면 삭제 |
| 쓴 리뷰·수정 이력 | 서비스 운영 기간 | 탈퇴하면 작성자를 '탈퇴한 회원'으로 바꿈 (내용은 다른 이용자를 위해 남음). 지우고 싶은 글은 탈퇴 전에 삭제 요청 |
| 쿠키 | 로그인 30일, 알림 읽음 60일 | 기간이 지나면 브라우저에서 사라짐, 로그아웃·탈퇴 시 바로 지움 |

전자적 파일은 복구할 수 없는 방법으로 지웁니다.

## 4. 제3자 제공

개인정보를 제3자에게 제공하지 않습니다.

## 5. 처리 위탁과 국외 이전

서비스를 운영하려고 다음 업체의 서비스를 씁니다.

| 업체 | 하는 일 | 저장 위치 | 옮겨 가는 정보 |
| --- | --- | --- | --- |
| Supabase | 데이터베이스 (회원·리뷰·북마크) | 대한민국(서울) 리전 | 2번의 모든 항목 |
| Streamlit (Snowflake) | 앱 서버 | 미국 | 서비스를 쓰는 동안 오가는 정보, 직접 올린 사진 파일 |
| Vercel | 공개 웹 서버 (읽기 전용) | 미국 | 접속 기록 (개인정보 저장 없음) |
| OpenAI | '물어보기' 답 만들기 | 미국 | 질문 글 (전화번호·이메일 등은 가린 뒤 보냄, 회원 정보는 보내지 않음) |
| 카카오 · 네이버 | 간편 로그인 인증 | 대한민국 | 로그인할 때 인증 정보 (서비스는 해시값만 저장) |

국외 이전은 서비스를 쓰는 시점에 인터넷으로 옮겨지며, 거부하려면 서비스를 쓰지 않거나 탈퇴하면 됩니다.

## 6. 이용자의 권리와 행사 방법

- **열람·정정:** 마이페이지(오른쪽 위 내 닉네임)에서 닉네임·프로필 사진을 보고 고칠 수 있습니다.
- **삭제·처리 정지:** 마이페이지의 **탈퇴하기**로 언제든 지울 수 있습니다. 프로필 사진은 '기본 사진 설정'을 누르면 바로 지워집니다.
- **동의 철회:** 선택 동의(프로필 사진)는 마이페이지에서 '기본 사진 설정'을 눌러 철회할 수 있습니다.

## 7. 만 14세 미만 아동

**만 14세 이상만 가입할 수 있습니다.** 만 14세 미만의 개인정보를 처리하려면 법정대리인 동의가 필요하지만, 이 서비스는 그 확인 절차를 아직 갖추지 않아 만 14세 미만의 가입을 받지 않습니다. 가입 화면에서 만 14세 이상인지 확인합니다.

## 8. 안전성 확보 조치

- 비밀번호는 **일방향 암호화(bcrypt)** 해서 저장하고, 원래 비밀번호는 어디에도 남기지 않습니다.
- 카카오·네이버 계정 번호와 손님 IP 는 소금 친 해시로 바꿔 원래 값을 알 수 없게 저장합니다.
- 모든 통신은 HTTPS 로 암호화합니다. 데이터베이스는 행 단위 보안(RLS)으로 고치기·지우기를 막습니다.
- 관리자 권한은 지정한 1명에게만 있습니다.
- 글에 개인정보(전화번호·이메일 등)가 들어 있으면 저장하지 않습니다.

# 이용약관 (요약)

1. **서비스:** 애니메이션 팝업·콜라보 카페 정보를 지도와 목록으로 보여 주고, 회원이 리뷰·북마크·정보 수정을 할 수 있게 합니다.
2. **가입:** 만 14세 이상만 가입할 수 있습니다. 다른 사람인 척하거나 욕설·음란한 닉네임은 쓸 수 없습니다.
3. **게시물:** 리뷰·수정한 정보에 대한 책임은 쓴 사람에게 있습니다. 욕설·광고·남의 개인정보·저작권을 침해하는 글은 관리자가 지울 수 있습니다. 다른 회원의 글은 '삭제 요청'으로 신고할 수 있습니다.
4. **정보의 정확성:** 팝업 정보는 자동 수집과 이용자 입력으로 모읍니다. 방문 전 공식 공지를 꼭 확인해 주세요. '기간 확인 필요'·'링크 확인 필요' 표시가 있는 정보는 특히 확인이 필요합니다.
5. **탈퇴:** 마이페이지에서 언제든 탈퇴할 수 있고, 개인정보는 개인정보처리방침 3번에 따라 지웁니다.
