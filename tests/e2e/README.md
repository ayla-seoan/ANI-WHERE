# Playwright QA — 핵심 흐름 자동 테스트

ANI:WHERE 를 실제 브라우저(Chromium)로 열어 사람이 쓰는 순서대로 눌러 보는 E2E 테스트입니다.

## 설치 (처음 한 번)

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m playwright install chromium
```

## 실행

```bash
python -m pytest tests/e2e -q          # 테스트만
python scripts/qa_report.py            # 테스트 + 한국어 결과표 + docs/qa-results.md 에 기록 덧붙이기
```

- 테스트가 직접 `streamlit run app_cafemap.py --server.port 8599` 를 띄우고, 끝나면 끕니다. 미리 앱을 켜 둘 필요가 없습니다.
- 8599 포트가 이미 쓰이고 있으면 멈춥니다. `E2E_PORT=8600` 처럼 바꿀 수 있습니다.
- 브라우저 창을 직접 보려면 `E2E_HEADED=1` 을 붙입니다.
- Windows 콘솔에서 한글이 깨지면 `PYTHONIOENCODING=utf-8` 을 붙입니다 (`qa_report.py` 는 알아서 붙입니다).

## 진짜 데이터는 건드리지 않습니다

- 시작할 때 `data/` 전체를 임시 폴더로 복사하고, 앱을 `ANIWHERE_DATA_DIR=<임시 폴더>` 로 띄웁니다 (`common/storage.py` 의 `LOCAL_DIR`).
  북마크를 누르거나 기간 지난 팝업이 자동으로 내려가도 임시 복사본에만 쌓입니다.
- `STORAGE_MODE=local`, `OPENAI_API_KEY`·`NOTION_TOKEN` 은 빈 값으로 띄웁니다. 키가 없어도 앱이 동작하는지도 함께 확인되는 셈입니다
  (빈 값이라 Notion 가져오기도 돌지 않습니다).
- 앱 로그는 임시 폴더의 `streamlit.log` 에 남습니다 (pytest 가 `tmp_path` 로 만든 폴더).

## 테스트가 증명하는 것

| # | 테스트 | 확인하는 것 |
| --- | --- | --- |
| 1 | `test_1_목록이_뜬다` | 첫 화면(리스트 전체보기)에 팝업 카드가 1장 이상 나오고, 머리글 `팝업 카페 N곳` 의 N 이 카드 수와 같다. |
| 2 | `test_2_검색으로_좁혀지고_없으면_안내가_뜬다` | 작품 이름으로 검색하면 그 팝업 카드가 남고 카드 수가 줄어든다. 말이 안 되는 검색어는 빈 표가 아니라 `조건에 맞는 카페가 없습니다…` 안내가 뜬다. |
| 3 | `test_3_카드를_누르면_상세가_열리고_돌아올_수_있다` | 카드를 누르면 상세가 열리고 작품 이름 · `방문 전 확인` · `참고 웹사이트` 가 보인다. `리스트로 돌아가기` 로 목록에 돌아온다. |
| 4 | `test_4_북마크하면_내_캘린더에_보인다` | 카드의 북마크 아이콘을 누르면 `/calendar` 의 내 캘린더(달력 막대와 `곧 있는 팝업`)에 그 팝업이 나온다. 끝나면 북마크를 해제하고 캘린더에서 빠졌는지까지 본다. |
| 5 | `test_5_리뷰에_전화번호를_넣으면_막힌다` | 상세의 리뷰 칸에 `010-1234-5678` 을 넣으면 `민감한 개인정보(전화번호)는 입력할 수 없습니다` 경고가 뜨고 `리뷰 등록` 버튼이 꺼진다. 눌러 봐도 `reviews.json` 은 한 글자도 바뀌지 않는다. |
| 6 | `test_6_모바일_390px에서_가로_스크롤이_없다` | 휴대폰 폭(390px)에서 목록 화면 내용 폭이 화면 폭을 넘지 않고(가로 스크롤 없음) 카드가 화면 안에 들어온다. |
| 7 | `test_7_손님이_북마크를_누르면_로그인_화면으로` | 로그인하지 않은 손님이 북마크를 누르면 저장하지 않고 로그인 화면으로 간다. |
| 8 | `test_8_등록은_회원만` | 손님에게는 등록(`+`)이 보이지 않고, 회원이 되면 등록하기가 열린다. |
| 9 | `test_9_로그아웃하면_새로고침해도_로그인되지_않는다` | 로그아웃 뒤 새로고침 · 다시 열기에도 로그인 상태로 돌아가지 않는다 (로그인 쿠키를 지움). |
| 10 | `test_10_새로_가입하면_북마크가_비어_있다` | 같은 브라우저에서 새 계정으로 가입하면 이전 계정의 북마크가 보이지 않는다 (회원마다 따로). |
| 11 | `test_11_팝업_북마크_추가로_고르면_관심있는_작품_맨_앞에_온다` | 홈 '최애 추가하기'로 고른 팝업이 북마크 팝업 줄 맨 앞에 온다. |
| 12 | `test_12_로고를_누르면_홈이_열리고_랭킹_카드로_상세에_간다` | 로고 → 홈, 실시간 랭킹 배너를 누르면 그 팝업 상세가 열린다. |
| 13 | `test_13_내_리뷰는_고칠때_사진을_붙이고_직접_지울_수_있다` | 내 리뷰를 고칠 때 사진을 새로 붙이고, 내 리뷰를 직접 지울 수 있다. |
| 14 | `test_14_디자인_시스템_페이지는_로그인_없이_열린다` | `/design` 이 로그인 없이 열린다. |
| 15 | `test_15_대댓글은_ᄂ_표시_사진_첨부_접어_두기` | 리뷰 등록은 빨라야 하고(조각만 다시 그림), 답글은 'ㄴ' 표시 · 사진 첨부 · '+N건의 댓글' 로 접었다 펼친다. |

결과는 날짜별로 [`docs/qa-results.md`](../../docs/qa-results.md) 에 쌓입니다 (11/25 · 11/27 · 11/28 모두 15/15).

## 고칠 때 참고

- Streamlit 화면은 다시 그릴 때마다 바뀌므로 위젯 키로 만든 클래스(`.st-key-card_w_<id>`, `.st-key-open_<id>`, `.st-key-fav_off_w_<id>`)와
  글자(`get_by_text` · `get_by_role`)로 찾습니다. 다시 그리기가 끝났는지는 `stStatusWidget` 이 사라지는 것으로 기다립니다.
- 어떤 팝업으로 시험할지는 임시 `cafes.json` 에서 고릅니다 (지금 목록에 나오는 것, 상세 테스트는 참고 웹사이트가 있는 것).
